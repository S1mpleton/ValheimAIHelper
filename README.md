# Valheim AI Helper

AI-напарник для Windows / Steam. Мод управляет обычным персонажем во втором клиенте Valheim. Управление: **Esc → Управление персонажем**, резервная клавиша **F8**, немедленный стоп **F9**.

[Скачать Windows 0.3.1](https://github.com/S1mpleton/ValheimAIHelper/releases/download/v0.3.1/ValheimAIHelper-windows-0.3.1.zip) · [Релиз и исходники](https://github.com/S1mpleton/ValheimAIHelper/releases/tag/v0.3.1) · [SHA256](https://github.com/S1mpleton/ValheimAIHelper/releases/download/v0.3.1/ValheimAIHelper-windows-0.3.1.zip.sha256)

## Установка и обновление

1. Закройте Valheim и прежнее окно Python-службы. Установите [BepInExPack Valheim](https://thunderstore.io/c/valheim/p/denikson/BepInExPack_Valheim/), если его ещё нет.
2. Распакуйте Windows-архив. Скопируйте из него **папку BepInEx** в каталог с `valheim.exe`, согласившись на замену файлов нашего плагина. Если старая DLL лежит непосредственно в `BepInEx/plugins/ValheimAIHelper.dll`, удалите эту старую копию, чтобы не загружались два плагина.
3. Сохраните **всю** папку `BepInEx/plugins/ValheimAIHelper`, включая `runtime` и `runtime/_internal`. Отдельная установка Python и запуск PowerShell больше не нужны.
4. Запустите игру и войдите персонажем помощника в мир лидера. Откройте **Esc → Управление персонажем**.
5. На вкладке **«Персонаж»** проверьте выбранного лидера и переключатели **«Бой»**, **«Еда»**, **«Чат лидера»**. Нажмите **«Следовать»** для проверки без модели.
6. На вкладке **«Подключение AI»** выберите провайдера, введите ключ, получите модели и выберите API-имя. Сохраните подключение. Затем на вкладке «Персонаж» задайте задачу и нажмите **«Выполнять задачу AI»**.

При обновлении ранее выключенный `Player.AllowCombat` сохраняется: включите «Бой» в новой панели, если хотите разрешить сражения.

Локальная служба поставляется в архиве, запускается модом в фоне и завершается вместе с этой игрой. Каждая копия игры получает свой локальный порт и код сопряжения. Сервер или окно браузера вручную запускать не требуется. Перезапуск службы находится во вкладке «Журнал»; после него API-ключ нужно ввести заново.

## Команды из чата лидера

Мод нужен на клиенте помощника. У лидера достаточно обычного игрового чата.

| Сообщение лидера | Результат |
| --- | --- |
| `!ai следуй` / `!ai follow` | Следовать без API-запросов |
| `!ai защищай меня и подбирай выпавшие предметы` | Передать нейросети задачу |
| `!ai съешь еду и экипируй лучшее оружие` | Задача по подготовке персонажа |
| `!ai стоп` / `!ai stop` | Немедленно прекратить управление |
| `!ai статус` / `!ai status` | Короткое состояние в чате |
| `!ai бой вкл` / `!ai бой выкл` | Разрешить/запретить бой |
| `!ai еда вкл` / `!ai еда выкл` | Включить/выключить автоматическую еду |
| `!ai помощь` | Подсказка |

Команды принимаются **только от выбранного лидера**, с проверкой сетевого владельца персонажа. Имя в тексте сообщения не даёт права управлять помощником. Обычный чат не передаётся модели. Вдали используйте игровой крик: `/s !ai следуй`. Дальность и разрешения общения остаются игровыми; при отключённой карте дальний чат может не поступить обработчику. Без видимого выбранного лидера приём команд закрыт.

## Что умеет версия 0.3

Приоритет сценария — **следовать → сражаться → выживать**.

Модель получает ближайших врагов с их здоровьем и целями, лидера, выпавшие предметы, растения для сбора и двери, инвентарь с типами/уроном/прочностью, активные слоты еды, оружие, биом, здоровье и выносливость. Она составляет план из 1–6 действий. Результат выполнения возвращается ей; неудачная подготовка отменяет зависимые шаги.

Между ответами API мотор продолжает следование/бой по свежим наблюдениям примерно раз в секунду. Пауза API по умолчанию — **20 секунд**, она ограничивает платные обращения, а не частоту движения. При сетевой потере управления отдельный ввод истекает максимум за 3 секунды.

| Управление | Реализация |
| --- | --- |
| Следование и перемещение | Маршруты игры, бег с запасом выносливости, короткие прыжки при препятствии |
| Бой | Подход, прицеливание, ближние удары, натяжение/отпускание лука, штатный ввод другого оружия |
| Защита | Блок, уклонение по плану, срочная защита себя/лидера без ожидания API |
| Выживание | Отступление при низком здоровье, восстановление выносливости, доступная еда через штатное использование |
| Снаряжение | Экипировка существующих вещей по плану модели |
| Сбор и взаимодействие | Подбор предметов, сбор растений, использование дверей через проверки игры |
| Расходники | Использование имеющихся расходников, без создания предметов |
| Меню и отчёты | Штатные шрифты/элементы Valheim, вкладки настроек и журнала, копирование/сохранение отчёта |

Это экспериментальный сценарий, **не автономное прохождение Valheim**. Крафт, стройка, рубка, добыча руды, сундуки, лодки, порталы и возрождение пока не реализованы. Качество боя и обхода препятствий требует проверки в настоящей игре. Оружию нужны обычные боеприпасы/выносливость/эйтр, ресурсам — место в инвентаре. Мод не меняет позиции, урон, сетевое владение или содержимое инвентаря напрямую.

## Ошибки и журнал

**Esc → Управление персонажем → Журнал → «Копировать отчёт»**. Можно сохранить файл в `BepInEx/config/ValheimAIHelper/reports`. Журнал содержит версию игры/мода, команды, планы, результаты, ошибки и состояние персонажа. Ключи и код сопряжения маскируются перед выводом и экспортом. Буфер ограничен 300 строками.

429 (квота/баланс) и 404 (модель недоступна) останавливают AI. 503 повторяется с паузами 2/4 секунды, затем действует минимум 15 секунд ожидания. Ручные проверки модели также расходуют квоту. Старый Gemini может оставаться в списке моделей, хотя генерация для новых пользователей закрыта: смотрите полный ответ API в журнале.

Ключ хранится только в памяти до закрытия службы/игры. Провайдер, модель, задача, лидер и переключатели сохраняются в конфигурации. Не добавляйте ключ в игровой чат: введите его в поле с маскировкой.

## Клиент и совместимость

Напарник остаётся отдельным обычным игроком: необходимы второй рабочий клиент/аккаунт и штатное подключение к миру. Реализации NPC внутри одного клиента в этой версии нет. Использование двух клиентов с одним Steam-аккаунтом уже вызывало рассинхронизацию и без мода; изменение AI этого не исправляет.

Мод компилируется против публичных ссылочных библиотек **Valheim 0.221.4**. Сборка и автотесты не доказывают совместимость с Valheim 1.0.21: запуск GUI, чата, боевого ввода и кооператива надо проверить в установленной игре. Если шаблоны игрового меню несовместимы, F8 открывает резервную панель с журналом. Включённый AI при открытом меню не управляет персонажем.

## Разработка

Нужны Python 3.12 и .NET SDK из `global.json`; Node.js используется только для синтаксической проверки диагностической веб-панели.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install --require-hashes -r bridge/requirements-dev.txt
PYTHONPATH=bridge/src .venv/bin/python -m pytest bridge/tests -q
.venv/bin/python scripts/smoke_bridge.py
python3 scripts/bootstrap_mod.py
dotnet test mod/ValheimAIHelper.Tests/ValheimAIHelper.Tests.csproj -c Release -p:RestoreLockedMode=true
dotnet build mod/ValheimAIHelper/ValheimAIHelper.csproj -c Release -p:RestoreLockedMode=true
.venv/bin/python scripts/check_wire.py
```

Для разработки без упакованной службы выключите `Bridge.AutoStart` в конфигурации. Python-мост: `PYTHONPATH=bridge/src .venv/bin/python -m valheim_ai`. Пусковые PowerShell-скрипты оставлены для такого режима; они не нужны пользователю готового Windows-архива.

Сборка Windows-службы (на Windows, после установки runtime-зависимостей):

```powershell
python -m pip install --require-hashes -r bridge/requirements-build.txt
python scripts/freeze_bridge.py
python scripts/smoke_frozen.py .local/frozen/ValheimAIBridge/ValheimAIBridge.exe
python scripts/package.py --runtime .local/frozen/ValheimAIBridge
```

CI проверяет Windows и Linux, затем запускает упакованный Windows EXE без каталога исходников, создаёт ZIP и публикует его в GitHub Releases только после успешных проверок обеих систем. Игровые/Unity/BepInEx DLL не входят в архив. При наличии установленной игры сборку можно проверить через `scripts/build-mod.ps1 -GameDir "путь к Valheim"`.

Подробнее: [архитектура](docs/architecture.md), [проверка в игре](docs/testing.md).
