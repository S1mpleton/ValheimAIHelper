# Valheim AI Helper

Экспериментальный AI-напарник для **Windows / Steam**: BepInEx-мод управляет обычным игровым персонажем, а локальный Python-сервис выбирает действия через **OpenAI / GPT** или **Google Gemini**. Управление находится прямо в игре: **Esc → AI-ПОМОЩНИК** (резервная клавиша — F8). Браузер для обычной работы не нужен.

**Это первый прототип, а не готовый игрок уровня человека.** Код мода собирается против ссылочных библиотек Valheim `0.221.4`. Автотесты сервиса и ограничений действий не заменяют проверку в самой игре: игровой запуск и совместимость с вашей версией Valheim ещё нужно проверить.

## Скачать

[Архив для Windows 0.2.0](https://github.com/S1mpleton/ValheimAIHelper/raw/refs/heads/main/dist/ValheimAIHelper-windows-0.2.0.zip) · [Контрольная сумма SHA256](dist/ValheimAIHelper-windows-0.2.0.zip.sha256)

Архив хранится прямо в Git в папке `dist`: его можно скачать с GitHub без доступа к этому чату. Внутри уже есть собранный плагин и пусковой скрипт; собирать DLL самостоятельно не нужно. Ниже — пошаговая установка.

**Обновление:** закройте игру и старую службу, распакуйте весь архив 0.2.0 и один раз выполните `scripts/start-windows.ps1 -GameDir "путь к Valheim"`. Обновятся DLL и Python-служба, сопряжение запишется автоматически. После входа в мир откройте **Esc → AI-ПОМОЩНИК**. Версия видна внизу панели.

Основные кнопки: **«Следовать»**, **«AI: выполнить задачу»**, **«Стоп»**. Ключ, провайдер и модель находятся в сворачиваемом разделе **«Подключение»**. «Следовать» работает без ключа и без обращений к модели. F9 немедленно возвращает ручное управление.

В 0.2.0 проверен настоящий запрос к **OpenAI `gpt-6-luna`**: получены HTTP 200 и валидное действие `wait`. У Gemini `gemini-3.8-flash` список/карточка модели вернулись с HTTP 200, а генерация — с HTTP 503 из-за высокой нагрузки. Это результаты отдельных проверок, не гарантия дальнейшей доступности сервиса. Обе новые серии используют низкий уровень рассуждения для коротких игровых команд.

Настраиваемая пауза между AI-решениями — 20 секунд по умолчанию. Повторы и ручные проверки тоже расходуют квоту. 429 останавливает AI; 503 повторяется с паузами 2/4 секунды, затем выдерживается 15 секунд. Локальное следование не ограничивается паузой API.

## Важное условие: отдельный клиент

Напарник — **настоящий персонаж во втором запущенном клиенте Valheim**, который подключается к вашему миру как обычный игрок. Это сохраняет штатные здоровье, выносливость, еду, инвентарь, физику, смерть и сохранения. Мод подаёт игровые команды, не создаёт ресурсы и не меняет характеристики.

Для Steam обычно нужны **второй аккаунт с собственной копией игры и отдельный компьютер** либо виртуальная машина, в которой реально запускается Valheim. Поддерживаемого запуска двух аккаунтов Steam на одном рабочем столе в проекте нет. В вашей основной копии мод не нужен. На клиенте напарника должны быть и мод, и локальный сервис.

**Если у вас одна копия игры и один компьютер, этот вариант пока не подходит.** NPC-мод, создающий помощника в одной копии, — отдельное возможное направление; в этой версии такого NPC нет.

## Что реализовано

| Действие | Как выполняется |
| --- | --- |
| Следовать за лидером | Пеший маршрут Valheim; без нейросети и API-платежей |
| Идти вперёд | Команда AI «Иди вперёд»: короткий пеший шаг по маршруту, до 3 секунд / 4 м за действие |
| Ждать | Нулевой ввод; персонаж остаётся в мире и может получать урон |
| Подбирать | Только существующие предметы на земле рядом, через игровой подбор |
| Есть | Только еда из собственного инвентаря, через штатное использование предмета |
| Экипироваться | Только существующие вещи в собственном инвентаре |
| Ближний бой | Экспериментально, включается отдельно; только враждебные монстры, уже атакующие напарника или лидера |
| Понимать задачу | Короткая текстовая задача для GPT/Gemini; объяснение решения в локальной панели |

Строительство, рубка деревьев, добыча руды, крафт, сундуки, передача предметов, дальний бой, лодки, порталы, сложные прыжки и автоматическое возрождение **не реализованы**. Если пешего маршрута нет, нужен человек. Напарник пока не способен самостоятельно пройти игру или надёжно выживать без присмотра.

## Установка на Windows

Все шаги ниже выполняются **на компьютере отдельного персонажа**. Сначала проверьте следование на тестовом мире.

1. Установите Steam-версию Valheim и [Python 3.12](https://www.python.org/downloads/windows/). В установщике Python включите Python Launcher / Add Python to PATH.
2. Установите [BepInExPack_Valheim](https://thunderstore.io/c/valheim/p/denikson/BepInExPack_Valheim/). Для ручной установки содержимое папки `BepInExPack_Valheim` должно оказаться рядом с `valheim.exe`. Запустите игру один раз и закройте её. Рядом с игрой должен быть `BepInEx/core/BepInEx.dll`.
3. Распакуйте подготовленный архив `ValheimAIHelper-windows-0.2.0.zip` в обычную доступную для записи папку. В нём есть `plugin/ValheimAIHelper.dll`, `bridge`, `scripts` и эта инструкция. Если вы скачали исходники из GitHub, сначала соберите мод по инструкции разработчика ниже.
4. Откройте PowerShell в распакованной папке и выполните:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-windows.ps1 -GameDir "C:\Program Files (x86)\Steam\steamapps\common\Valheim"
   ```

   Подставьте ваш путь к игре. Разрешение выполнения относится только к этому запуску PowerShell. Скрипт копирует наш плагин в `BepInEx/plugins/ValheimAIHelper`, устанавливает закреплённые Python-зависимости в `.venv` и записывает код сопряжения в конфигурацию мода. Другую версию нашего DLL при замене сохраняет с расширением `.previous`. Игру нужно закрыть до выполнения скрипта. Окно сервиса оставьте открытым.

5. Запустите модифицированный Valheim, войдите отдельным персонажем в кооперативный мир и подойдите к лидеру.
6. Нажмите **Esc → AI-ПОМОЩНИК → «Следовать»**. Подключение выполняется автоматически; копировать код сопряжения в игру не требуется. Если пункт меню отсутствует, откройте панель через F8.
7. Для нейросети раскройте **«Подключение»**, выберите OpenAI или Gemini, вставьте API-ключ и нажмите **«Получить модели»**. При наличии в списке предлагается `gpt-6-luna` или `gemini-3.8-flash`; другую модель можно выбрать вручную. Напишите задачу и нажмите **«AI: выполнить задачу»** — настройки сохранятся и управление запустится. «Проверить модель» — необязательный диагностический запрос, тоже расходующий квоту.

## Повторный запуск службы

После первоначальной установки можно запускать только службу, не закрывая игру:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-bridge.ps1
```

Окно службы нужно оставить открытым. Она использует Python и тот же локальный каталог данных; запуск из другой распакованной копии может потребовать повторного сопряжения через установщик. Настройки управления меняются в игре. Пауза/меню помощника не выполняет новые AI-решения после начального соединения с персонажем.

## Что хранится

API-ключ вводится в поле с маскировкой и передаётся только локальной службе. Он живёт в памяти до её завершения, не записывается в конфигурацию игры. Провайдер, модель, задача и интервал сохраняются как обычные настройки. Не публикуйте ключи, код сопряжения или полную конфигурацию.

Лидер — ближайший другой живой игрок при включении управления. Для явного выбора задайте `Player.LeaderName` в `BepInEx/config/dev.valheim.aihelper.cfg`. После исчезновения выбранного лидера помощник останавливается. Мод управляет текущим локальным персонажем, не создаёт NPC.

## Проверка и совместимость

Открытая панель блокирует ввод персонажа и камеры так же, как игровое меню. В одиночном режиме используется штатная пауза игры. Навигация и сетевые компоненты остаются игровыми. Сборка использует ссылочные библиотеки Valheim 0.221.4; совместимость и отрисовку на настоящей установленной игре нужно проверить, особенно для версии 1.0.21.

Веб-панель `http://127.0.0.1:8765` оставлена как дополнительный диагностический интерфейс. Для неё по-прежнему нужен код из `.local/bridge-token`; игровой интерфейс использует сопряжение из конфигурации автоматически. Открывать порт в Интернет не нужно.

## Разработка

Требования: Python 3.11/3.12, .NET SDK **8.0.427**, Node.js только для проверки JavaScript. Используйте существующую копию репозитория; отдельный Git worktree не нужен.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install --require-hashes -r bridge/requirements-dev.txt
export PYTHONPATH="$PWD/bridge/src"
.venv/bin/python -m pytest bridge/tests -q
.venv/bin/python scripts/smoke_bridge.py
.venv/bin/python scripts/check_wire.py
python3 scripts/bootstrap_mod.py
dotnet test mod/ValheimAIHelper.Tests/ValheimAIHelper.Tests.csproj -c Release -p:RestoreLockedMode=true
dotnet build mod/ValheimAIHelper/ValheimAIHelper.csproj -c Release -p:RestoreLockedMode=true
.venv/bin/python scripts/package.py
```

Для сервиса без установленной игры: `PYTHONPATH=bridge/src .venv/bin/python -m valheim_ai`. Проверка готовности: `GET /health` → `{"status":"ok","protocol_version":1,"version":"0.2.0"}`. Пока нет наблюдений мода, панель корректно показывает ожидание игры.

На Windows сборка: `powershell -File .\scripts\build-mod.ps1`. Чтобы проверить сборку против **вашей установленной версии игры**, добавьте `-GameDir "путь к Valheim"`. Ссылочные пакеты из NuGet позволяют собирать код в CI без установки Valheim; они не исполняют игру и не доказывают её совместимость. DLL игры, Unity и BepInEx в наш архив не включаются.

Подробности: [архитектура и протокол](docs/architecture.md), [проверка в игре и устранение проблем](docs/testing.md).
