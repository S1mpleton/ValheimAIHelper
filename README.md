# Valheim AI Helper

Экспериментальный AI-напарник для **Windows / Steam**: BepInEx-мод управляет обычным игровым персонажем, а локальный Python-сервис выбирает действия через **OpenAI / GPT** или **Google Gemini**. Провайдера, модель и задачу можно менять в русскоязычной панели.

**Это первый прототип, а не готовый игрок уровня человека.** Код мода собирается против ссылочных библиотек Valheim `0.221.4`. Автотесты сервиса и ограничений действий не заменяют проверку в самой игре: игровой запуск и совместимость с вашей версией Valheim ещё нужно проверить.

## Скачать

[Архив для Windows 0.1.4](https://github.com/S1mpleton/ValheimAIHelper/raw/refs/heads/main/dist/ValheimAIHelper-windows-0.1.4.zip) · [Контрольная сумма SHA256](dist/ValheimAIHelper-windows-0.1.4.zip.sha256)

Архив хранится прямо в Git в папке `dist`: его можно скачать с GitHub без доступа к этому чату. Внутри уже есть собранный плагин и пусковой скрипт; собирать DLL самостоятельно не нужно. Ниже — пошаговая установка.

**Обновление:** закройте игру и старый сервис, распакуйте весь архив 0.1.4 и запустите `scripts/start-windows.ps1` с вашим `-GameDir`. Обновите и DLL, и сервис; F8 должна показывать **0.1.4**. В браузере нажмите Ctrl+F5 и выполните сопряжение.

Для Gemini выберите провайдера, введите API-ключ и нажмите **«Получить модели Gemini»**. Можно использовать уже применённый ключ. Список содержит модели API с поддержкой `generateContent`; выберите имя в выпадающем списке «Модели из API Google» и примените настройки. Поле «API-имя модели» обновится после вашего выбора. Ручной ввод сохранён. Наличие в списке не гарантирует поддержку JSON-схемы выбранной моделью. Если текущего имени нет в полученном списке, панель покажет предупреждение. При HTTP 404 AI останавливается после первого отказа: выберите доступную модель, примените настройки и снова включите AI. Конкретная модель Gemini больше не подставляется автоматически. Если все модели возвращают 404, нажмите **«Проверить выбранную модель»**. Проверка последовательно запрашивает карточку модели, простую генерацию и генерацию действия со схемой. Результат показывает, на каком шаге произошёл отказ, и пояснение Google после удаления ключей. Два запроса генерации могут расходовать баланс и квоту. Настройки облачной среды Codex не влияют на мост, запущенный на вашем Windows-компьютере.

**Квоты:** HTTP 429 означает превышение лимита/проблему баланса; AI останавливается до повторного включения оператором. Установите паузу между решениями в панели (по умолчанию **20 секунд**, около 3 решений в минуту). Повторы и проверки тоже входят в квоту. Дневной лимит 20 запросов позволяет лишь короткие AI-сессии даже с такой паузой. Режим «Просто следовать» не обращается к API и не замедляется этой настройкой.

**Следование и сеть:** в 0.1.4 сохранён штатный `PlayerController`, а движение подаётся как обычный ввод через `SetControls`. В 0.1.3 контроллер отключался, а направление задавалось напрямую. Это изменение пути ввода требует проверки в реальной совместной игре: исправление видимых другому игроку откатов пока не подтверждено. Cross-play включайте, если она нужна для подключения. Библиотеки для сборки всё ещё относятся к Valheim 0.221.4; совместимость с указанной пользователем 1.0.21 в облаке не проверялась. Строка `Valheim version: ...` в BepInEx/LogOutput.log показывает версию, определённую самим API игры.

Одна попытка API ограничена 30 секундами. При HTTP 503 выполняются ещё две попытки с паузами 2 и 4 секунды; после трёх отказов новые решения ждут 15 секунд. Общий предел моста — 100 секунд, мода — 110 секунд. Во время ожидания персонаж не удерживает управление; F9 немедленно возвращает его человеку. Долгий запрос не должен ошибочно отключать индикатор подключения.

## Важное условие: отдельный клиент

Напарник — **настоящий персонаж во втором запущенном клиенте Valheim**, который подключается к вашему миру как обычный игрок. Это сохраняет штатные здоровье, выносливость, еду, инвентарь, физику, смерть и сохранения. Мод подаёт игровые команды, не создаёт ресурсы и не меняет характеристики.

Для Steam обычно нужны **второй аккаунт с собственной копией игры и отдельный компьютер** либо виртуальная машина, в которой реально запускается Valheim. Поддерживаемого запуска двух аккаунтов Steam на одном рабочем столе в проекте нет. В вашей основной копии мод не нужен. На клиенте напарника должны быть и мод, и локальный сервис.

**Если у вас одна копия игры и один компьютер, этот вариант пока не подходит.** NPC-мод, создающий помощника в одной копии, — отдельное возможное направление; в этой версии такого NPC нет.

## Что реализовано

| Действие | Как выполняется |
| --- | --- |
| Следовать за лидером | Пеший маршрут Valheim; без нейросети и API-платежей |
| Идти вперёд | Команда AI «Иди вперёд»: короткий пеший шаг по маршруту, до 3 секунд / 4 м за действие |
| Ждать | Нулевой ввод; персонаж остаётся в мире и может получать урон |
| Подбирать | Только существующие предметы на земле рядом, через игровой подбор |
| Есть | Только еда из собственного инвентаря, через штатное использование предмета |
| Экипироваться | Только существующие вещи в собственном инвентаре |
| Ближний бой | Экспериментально, включается отдельно; только враждебные монстры, уже атакующие напарника или лидера |
| Понимать задачу | Короткая текстовая задача для GPT/Gemini; объяснение решения в локальной панели |

Строительство, рубка деревьев, добыча руды, крафт, сундуки, передача предметов, дальний бой, лодки, порталы, сложные прыжки и автоматическое возрождение **не реализованы**. Если пешего маршрута нет, нужен человек. Напарник пока не способен самостоятельно пройти игру или надёжно выживать без присмотра.

## Установка на Windows

Все шаги ниже выполняются **на компьютере отдельного персонажа**. Сначала проверьте следование на тестовом мире.

1. Установите Steam-версию Valheim и [Python 3.12](https://www.python.org/downloads/windows/). В установщике Python включите Python Launcher / Add Python to PATH.
2. Установите [BepInExPack_Valheim](https://thunderstore.io/c/valheim/p/denikson/BepInExPack_Valheim/). Для ручной установки содержимое папки `BepInExPack_Valheim` должно оказаться рядом с `valheim.exe`. Запустите игру один раз и закройте её. Рядом с игрой должен быть `BepInEx/core/BepInEx.dll`.
3. Распакуйте подготовленный архив `ValheimAIHelper-windows-0.1.4.zip` в обычную доступную для записи папку. В нём есть `plugin/ValheimAIHelper.dll`, `bridge`, `scripts` и эта инструкция. Если вы скачали исходники из GitHub, сначала соберите мод по инструкции разработчика ниже.
4. Откройте PowerShell в распакованной папке и выполните:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-windows.ps1 -GameDir "C:\Program Files (x86)\Steam\steamapps\common\Valheim"
   ```

   Подставьте ваш путь к игре. Разрешение выполнения относится только к этому запуску PowerShell. Скрипт копирует наш плагин в `BepInEx/plugins/ValheimAIHelper`, устанавливает закреплённые Python-зависимости в `.venv` и записывает код сопряжения в конфигурацию мода. Другую версию нашего DLL при замене сохраняет с расширением `.previous`. Игру нужно закрыть до выполнения скрипта. Окно сервиса оставьте открытым.

5. В браузере **на этом же компьютере** введите адрес `http://127.0.0.1:8765`. Откройте созданный файл `.local/bridge-token` в Блокноте и скопируйте код в поле подключения. Не публикуйте этот код.
6. Запустите модифицированный Valheim, выберите отдельного персонажа и вручную войдите в ваш кооперативный мир. Подойдите им к вашему основному персонажу. Нажмите **F8 → «Включить для этого персонажа»**.
7. В браузере нажмите **«Просто следовать»**. Это первый тест: нейросеть и платный ключ не нужны. Напарник должен идти за лидером, а при недоступном маршруте остановиться.
8. После проверки выберите OpenAI или Gemini, укажите модель и **API-ключ**, нажмите «Применить настройки», задайте задачу и нажмите «Включить AI». Ключ проверяется первым реальным запросом из игры. Выбор провайдера сам по себе не делает платных запросов.

Если используете r2modman, укажите каталог активного профиля, содержащий `BepInEx`, через ручную установку нашего DLL в профиль; скрипт рассчитан на установку рядом с `valheim.exe`. Проще начать с отдельной ручной установки BepInEx. Не устанавливайте вторую копию DLL поверх того же плагина в другом профиле.

## Ключи GPT и Gemini

- OpenAI: создайте API-ключ в [панели API](https://platform.openai.com/api-keys). Начальная модель — `gpt-4.1-mini`.
- Gemini: создайте ключ в [Google AI Studio](https://aistudio.google.com/apikey). Начальная модель — `gemini-2.5-flash`.
- Доступность моделей, регионов, квот и цены определяет провайдер. Можно указать другую совместимую модель с поддержкой структурированного JSON. Подписки ChatGPT Plus / Gemini сами по себе не предоставляют баланс API.
- Ключи, введённые в панели, хранятся **только в памяти сервиса** до его закрытия. Перезапуск требует повторного ввода. Дополнительно поддерживаются переменные процесса `VALHEIM_OPENAI_API_KEY` и `VALHEIM_GEMINI_API_KEY`. Файл `.env` автоматически не читается.
- Модель получает имя и состояние персонажа, позиции и имена видимых целей, инвентарь и задачу. Игровые файлы, пароль сервера и экран не отправляются.
- По умолчанию цикл начинается не чаще раза в 4 секунды: до **900 запросов в час** плюс время ответа API. Поставьте лимит расходов у провайдера. Параметр `Bridge.DecisionInterval` можно увеличить до 60 секунд; каждое отдельное действие всё равно длится максимум 3 секунды.

## Управление и конфигурация

**F8** — панель мода. **F9** — немедленно отключить AI и вернуть клавиатуру/мышь текущему персонажу. Кнопка «Стоп» в браузере останавливает следующие действия, но оставляет мод включённым; уже начатое движение завершится максимум через 3 секунды. При смерти и выходе из мира мод возвращает ручное управление. Возрождение и повторное включение выполняются человеком.

Конфигурация: `BepInEx/config/dev.valheim.aihelper.cfg`. Пример несекретных настроек:

```ini
[Bridge]
Url = http://127.0.0.1:8765
DecisionInterval = 4

[Player]
LeaderName = ИмяВашегоОсновногоПерсонажа
AllowCombat = false
```

Параметр `Bridge.Token` записывает пусковой скрипт; не заменяйте его API-ключом. Изменяйте файл при закрытой игре. Без `LeaderName` мод один раз выбирает ближайшего другого игрока в радиусе 60 м и сохраняет этот выбор до отключения. При потере лидера он останавливается, не переключаясь на случайного игрока. Лучше задать имя явно.

Если API недоступен, нет ключа, пришёл неверный ответ или цель исчезла, новая команда не исполняется. Пока модель думает, персонаж стоит. Игра по-прежнему может убить его — остановка не включает неуязвимость. Нейросеть не имеет доступа к консоли или произвольному коду. Мост слушает только локальный интерфейс; открывать порт в Интернет не нужно.

## Разработка

Требования: Python 3.11/3.12, .NET SDK **8.0.427**, Node.js только для проверки JavaScript. Используйте существующую копию репозитория; отдельный Git worktree не нужен.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install --require-hashes -r bridge/requirements-dev.txt
export PYTHONPATH="$PWD/bridge/src"
.venv/bin/python -m pytest bridge/tests -q
.venv/bin/python scripts/smoke_bridge.py
.venv/bin/python scripts/check_wire.py
python3 scripts/bootstrap_mod.py
dotnet test mod/ValheimAIHelper.Tests/ValheimAIHelper.Tests.csproj -c Release -p:RestoreLockedMode=true
dotnet build mod/ValheimAIHelper/ValheimAIHelper.csproj -c Release -p:RestoreLockedMode=true
.venv/bin/python scripts/package.py
```

Для сервиса без установленной игры: `PYTHONPATH=bridge/src .venv/bin/python -m valheim_ai`. Проверка готовности: `GET /health` → `{"status":"ok","protocol_version":1,"version":"0.1.4"}`. Пока нет наблюдений мода, панель корректно показывает ожидание игры.

На Windows сборка: `powershell -File .\scripts\build-mod.ps1`. Чтобы проверить сборку против **вашей установленной версии игры**, добавьте `-GameDir "путь к Valheim"`. Ссылочные пакеты из NuGet позволяют собирать код в CI без установки Valheim; они не исполняют игру и не доказывают её совместимость. DLL игры, Unity и BepInEx в наш архив не включаются.

Подробности: [архитектура и протокол](docs/architecture.md), [проверка в игре и устранение проблем](docs/testing.md).
