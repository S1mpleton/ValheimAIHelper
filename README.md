# Valheim AI Helper

AI-напарник для Windows / Steam. Мод управляет обычным персонажем во втором клиенте Valheim. **Esc → Управление персонажем**, резервная клавиша **F8**, немедленный стоп **F9**.

[Скачать Windows 0.4.1](https://github.com/S1mpleton/ValheimAIHelper/releases/download/v0.4.1/ValheimAIHelper-windows-0.4.1.zip) · [Релиз и исходники](https://github.com/S1mpleton/ValheimAIHelper/releases/tag/v0.4.1) · [SHA256](https://github.com/S1mpleton/ValheimAIHelper/releases/download/v0.4.1/ValheimAIHelper-windows-0.4.1.zip.sha256)

## Установка

1. Закройте Valheim и прежнее окно Python-службы, если оно осталось от старых версий. Установите [BepInExPack Valheim](https://thunderstore.io/c/valheim/p/denikson/BepInExPack_Valheim/), если его ещё нет.
2. Скопируйте **папку BepInEx из Windows ZIP** в каталог с `valheim.exe`, заменив файлы нашего плагина. Старую отдельную `BepInEx/plugins/ValheimAIHelper.dll` удалите, если она осталась вне папки плагина.
3. Сохраните всю `BepInEx/plugins/ValheimAIHelper`, включая `runtime/_internal`. **Python, PowerShell и браузер для обычного запуска не требуются.** Мод запускает и завершает свою локальную службу.
4. Войдите персонажем помощника в мир лидера. Откройте Esc → «Управление персонажем» или F8. Выберите лидера. В «Персонаж → Дополнительно» находятся бой, еда и управление: «Только лидер» или «Все игроки». Прежнее выключенное разрешение боя сохраняется при обновлении.
5. «Следовать» работает без ключа. Для нейросети на вкладке «Подключение AI» выберите провайдера, введите ключ, получите модели и сохраните подключение. «Включить AI» начинает сопровождение/выживание; конкретные поручения вводятся в игровом чате.

В 0.4.1 исправлен MethodAccessException от защищённого GetRightItem. Окно следует масштабу игрового Canvas и ограничивается размером штатных настроек/экрана. У пункта Esc ограничен размер шрифта и есть подсветка; вкладки выделены общей полосой и индикатором выбора. Поле задачи убрано. При ошибке наблюдения журнал содержит полное исключение со стеком.

## Общение без !ai

Обратитесь по **настоящему имени персонажа помощника**:

- «Бъерн, подбери камни».
- «Бъерн, выбрось 5 камней».
- «Бъерн, сложи лишнее дерево в сундук».
- «Бъерн, почини инструменты на верстаке».
- «Бъерн, следуй за мной», «Бъерн, не сражайся», «Бъерн, стоп».
- Затем можно продолжить: «И ещё собери эти ягоды» — модель решит по контексту, к кому обращаются.

Именованные стоп/следование/статус обрабатываются локально. Произвольная задача передаётся модели. Без имени сообщения разрешённых игроков разбираются вместе с очередным планом AI; при обычном следовании/ожидании возможен отдельный запрос классификации. Учитывается текущая задача и короткий разговор с именами отправителей. Неопределённая реплика не должна заменять задачу. Обработка зависит от ответа модели и интервала API; имя — явный адресат.

Мод нужен только на клиенте помощника. По умолчанию управляет только выбранный лидер. В «Персонаж → Дополнительно» можно разрешить управление всем игрокам. В обоих режимах сверяется настоящий сетевой отправитель, совпадение отображаемого имени не даёт доступа. Смена разрешения отменяет текущую задачу и очередь сообщений. В режиме всех игроков именованное «за мной» выбирает отправителя лидером. Для дальнего сообщения используйте игровой крик `/s`; действуют штатные ограничения общения. Старый `!ai` оставлен для совместимости, но не обязателен.

Сообщения разрешённых игроков могут отправляться выбранному провайдеру для определения контекста. API-ключ вводится в поле настроек, не в чат. Прежний конфигурационный `Player.LeaderChat=false` отключает приём; выбор доступа в «Дополнительно» включает его снова.

## Как AI взаимодействует с игрой

**Снимок игры → план модели → штатный игровой обработчик → фактический результат в следующем снимке.**

Модель получает инвентарь, вес/место, здоровье/выносливость/эйтр, еду, эффекты, укрытие/комфорт/погоду, врагов и их цели, лидера, ресурсы, станции, открытые рецепты и доступные детали. Изменение мира выполняет мод через игровые методы и ввод, без исполнения сгенерированного кода.

Каталог содержит **40 команд**:

| Область | Возможности |
| --- | --- |
| Движение | Следовать, идти к точке, бежать, прыгать, смотреть, красться |
| Бой и выживание | Основной/вторичный удар, лук/прицеливание, блок, уклонение, отступление, охота, сила Хранителя |
| Инвентарь | Подобрать, съесть, использовать, экипировать, снять, убрать/достать оружие, сбросить количество вещей |
| Хранение | Открыть/закрыть контейнер, взять/положить количество, сложить совпадающие стопки |
| Ресурсы и станции | Топор/кирка, сбор растений, топливо/сырьё через входы станции, получение готового |
| Ремесло | Крафт, улучшение и ремонт через штатный интерфейс с обычными требованиями |
| Стройка и посадки | Доступные детали молота/культиватора, штатный предпросмотр, размещение и ремонт строения |
| Отдых и общение | Сесть/встать, отдых, сон в собственной кровати, жесты и игровой чат |

[Полный каталог, ограничения и ссылки на изученную вики](docs/mechanics.md).

План содержит до 6 шагов с обратной связью. Навигация и срочная защита продолжаются между ответами модели. AI может выбирать полезные действия самостоятельно, но явные пожелания лидера приоритетны; политика избегания боя запрещает атакующие шаги. Неудачная предпосылка отменяет зависимые шаги.

Все ресурсы, боеприпасы, прочность, требования станций, доступ к сундуку и размещение проверяет игра. Содержимое закрытого контейнера не раскрывается модели. Крафт ждёт реального результата; сброс ограничен существующим количеством вещей. Предметы для еды/экипировки используются из инвентаря, чтобы объект под прицелом не перехватил их использование.

Это экспериментальный помощник, **не автономное прохождение Valheim**. Корабельный автопилот, рыбалка, торговля, порталы и возрождение пока не реализованы. Сложная стройка, длинные цепочки и качество тактики требуют проверки в игре.

## Служба, квоты и журнал

Служба из Windows-архива работает в фоне, на своём loopback-порту и с отдельным кодом сопряжения для этой игры. Завершается вместе с ней. После перезапуска службы API-ключ нужно ввести заново: он хранится только в памяти. Модель, провайдер, задача и переключатели сохраняются как обычные настройки.

Пауза между автоматическими запросами AI — **20 секунд по умолчанию**. Это ограничивает API-вызовы, а не частоту движения: мод отправляет свежие наблюдения примерно раз в секунду, отдельный ввод истекает максимум за 3 секунды. Ручные проверки и новые задачи тоже расходуют квоту. 404/429 останавливают AI и возвращают ручное управление; 503 повторяется с паузами 2/4 секунды и последующим ожиданием минимум 15 секунд. F9 отменяет ожидающие команды, включая разбор чата.

**Esc/F8 → Журнал → «Копировать отчёт»** или «Сохранить в файл». Файлы — `BepInEx/config/ValheimAIHelper/reports`. В отчёте версии, планы, результаты и причины отказа; ключи и код сопряжения маскируются. Полная конфигурация и HTTP-тела с ключами не экспортируются. Для ошибок меню 0.4 записывает подробную причину, а не только InvalidOperationException.

## Совместимость

Помощник остаётся отдельным обычным игроком: нужны второй рабочий клиент/аккаунт и штатное подключение к миру. NPC внутри одного клиента в этой версии нет. Проблемы кооператива, повторяющиеся при ручной игре без мода, сначала проверяются на стороне базового подключения.

Сборка использует публичные ссылки **Valheim 0.221.4**. Они позволяют компилировать код без установки игры, но не подтверждают отрисовку и игровую совместимость с 1.0.21. Здесь проверяются код, протокол, Windows/Linux CI и запуск упакованной службы; реальный GUI/бой/стройка требуют игрового теста.

## Разработка

Нужны Python 3.12, .NET SDK из `global.json`; Node.js — для проверки дополнительной веб-диагностики.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install --require-hashes -r bridge/requirements-dev.txt
PYTHONPATH=bridge/src .venv/bin/python -m pytest bridge/tests -q
.venv/bin/python scripts/smoke_bridge.py
python3 scripts/bootstrap_mod.py
dotnet test mod/ValheimAIHelper.Tests/ValheimAIHelper.Tests.csproj -c Release -p:RestoreLockedMode=true
dotnet build mod/ValheimAIHelper/ValheimAIHelper.csproj -c Release -p:RestoreLockedMode=true
.venv/bin/python scripts/check_wire.py
```

Для внешнего Python-моста выключите `Bridge.AutoStart` в конфигурации. Разработческий запуск: `PYTHONPATH=bridge/src .venv/bin/python -m valheim_ai`. PowerShell-скрипты оставлены для разработки; пользователь Windows-архива их не запускает.

На Windows после установки runtime-зависимостей:

```powershell
python -m pip install --require-hashes -r bridge/requirements-build.txt
python scripts/freeze_bridge.py
python scripts/smoke_frozen.py .local/frozen/ValheimAIBridge/ValheimAIBridge.exe
python scripts/package.py --runtime .local/frozen/ValheimAIBridge
```

CI публикует архив в GitHub Releases после проверок Windows и Linux и запуска упакованного EXE вне каталога исходников. Игровые/Unity/BepInEx DLL в архив не включаются. Для проверки по установленным библиотекам игры используйте `scripts/build-mod.ps1 -GameDir "путь к Valheim"`.
