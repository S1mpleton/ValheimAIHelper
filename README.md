# Valheim AI Helper

AI-напарник для Windows / Steam: **один клиент Valheim + отдельный NPC**. Ваш персонаж остаётся под вашим управлением. Меню: **Esc → Управление персонажем**, резервная клавиша **F8**, немедленный стоп NPC **F9**.

[Скачать Windows 0.7.1](https://github.com/S1mpleton/ValheimAIHelper/releases/download/v0.7.1/ValheimAIHelper-windows-0.7.1.zip) · [Релиз и исходники](https://github.com/S1mpleton/ValheimAIHelper/releases/tag/v0.7.1) · [SHA256](https://github.com/S1mpleton/ValheimAIHelper/releases/download/v0.7.1/ValheimAIHelper-windows-0.7.1.zip.sha256)

## Установка и запуск

1. Закройте игру. Установите [BepInExPack Valheim](https://thunderstore.io/c/valheim/p/denikson/BepInExPack_Valheim/), если его ещё нет.
2. Скопируйте **BepInEx из ZIP** в каталог с `valheim.exe`, заменив файлы плагина. Удалите старую отдельную копию `BepInEx/plugins/ValheimAIHelper.dll`, если она осталась вне папки плагина. Нужна вся папка `BepInEx/plugins/ValheimAIHelper`, включая `runtime/_internal`.
3. Запустите **одну** игру своим обычным персонажем. Откройте свой одиночный мир либо запустите мир как хост. **Python, PowerShell, браузер и второй аккаунт не нужны.**
4. Esc → «Управление персонажем» → «Персонаж». Задайте имя помощника (по умолчанию **Гоша**), нажмите **«Создать / найти NPC»**. Лидер по умолчанию — текущий локальный игрок; старое имя второго клиента игнорируется. Удалённого игрока можно выбрать явно. Повторное нажатие находит существующего NPC; новый инвентарь не копируется из профиля игрока.
5. **«Следовать»** работает без модели. Для AI откройте «Подключение AI», выберите Ollama / OpenAI / Gemini, получите список моделей, проверьте и сохраните подключение. Вернитесь в «Персонаж» и включите AI.
6. Поручения задаются в игровом чате. Настройки боя, еды и доступа «Только лидер / Все игроки» находятся в «Персонаж → Дополнительно».

Версия 0.7 меняет архитектуру. Персонаж старого второго клиента автоматически в NPC не импортируется. NPC начинает с отдельным пустым инвентарём: вещи ему можно поручить подобрать с земли. [Создание, сохранение, ограничения и проверка NPC](docs/npc.md).

## Общение

- **«Следуй за мной»** (также «Гоша, следуй за мной») — единственная быстрая фраза следования без модели.
- **«Гоша, пошли»**, «пойдём», «за мной», другие перефразировки — смысл определяет AI и выбирает действие. Пока ответ не получен, новая задача не превращается в следование по словарю синонимов.
- «Гоша, дай мне 5 камней», «Гоша, отдай все камни», **«Гоша, отдай мне все свои вещи»**.
- «Гоша, подбери выпавшее дерево», «Гоша, поешь», «Гоша, защити меня».
- Продолжения без имени разбираются AI по контексту. Имя NPC явно обозначает адресата. Стоп/F9 остаётся немедленным; служебные статус/помощь доступны локально.

Проверяется настоящий сетевой отправитель. В режиме «Все игроки» выбранное моделью следование или точная быстрая фраза могут переключить лидера на отправителя. Сообщения разрешённых игроков могут отправляться выбранному провайдеру; ключ вводится в настройках, не в чат.

## Предметы и навигация

Выпавшие вещи (`pickup`) не требуют инструментов. Растения собираются через `interact`, деревья/залежи — через `gather` с подходящим инструментом. Гриб не выдаётся за добываемую залежь из-за наличия Destructible. [Как устроены навыки и атомарные шаги](docs/skills.md).


NPC видит загруженные `ItemDrop` до 128 м, ближайшие 80 стопок, их количества/вес и собственный инвентарь. Невидимые и ещё не загруженные сетевые объекты не раскрываются. Закрытый сундук не раскрывает содержимое.

Передача: **подойти к текущему положению получателя → остановиться рядом → сбросить количество → проверить изменение инвентаря**. Это предметы на земле, которые получатель подбирает обычным способом. Точное количество может охватывать несколько одинаковых стопок; «все камни» и «все вещи» исполняются одной проверяемой составной операцией. Квестовые предметы сохраняются. При частичном отказе сообщается реальное количество; исходная выдача автоматически не повторяется.

Следование удерживает дистанцию 2,5–4 м и отслеживает лидера в загруженной области до 128 м. Навигация использует штатную сетку путей, повторяет поиск, проверяет близкие подходы и фактическое продвижение. NPC не телепортируется к лидеру и не проходит сквозь препятствия. Для невыполнимого пути в чате появляется причина. [Действия и сценарии проверки](docs/actions.md).

## Ollama и диагностика

Ollama работает на том же ПК, стандартный адрес `http://127.0.0.1:11434`, API-ключ не нужен. Модель загрузите заранее в Ollama. Все запросы используют **think=false**. При смене модели служба сначала выгружает остальные запущенные модели Ollama; веса не удаляются. [Подробности](docs/ollama.md).

Снимки мира обновляются примерно раз в секунду, минимальный интервал запросов модели — 20 секунд по умолчанию. Устойчивое следование не вызывает модель по одному только таймеру; новые сообщения обрабатываются. Ожидание локальной генерации — до 300 секунд; движение по подтверждённому плану продолжается. Маленькая модель может быстро отвечать правильным JSON и ошибаться в смысле поручения. Скорость/фазы запроса и токены/секунду видны в «Персонаж» и «Журнал».

В 0.7.1 UI не пересканирует типы/иерархию при каждом наведении. Вкладки строятся по мере открытия; строки `ui-time` показывают время окна.

**Журнал → Диалог AI** показывает отправленный контекст, сырой ответ и результат проверки без нового запроса модели. Есть копирование и экспорт. **Журнал → Копировать отчёт** включает версии, NPC/человека, действия, инвентарь и исключения; ключи маскируются. [Просмотр диалога](docs/dialogue.md).

Служба из архива запускается модом и завершается с игрой. API-ключи хранятся только в памяти; Ollama и её веса в ZIP не входят. Ошибки 404/429 останавливают AI; облачный 503 повторяется с паузами 2/4 секунды и затем не менее 15 секунд ожидания. F9 отменяет ожидающие запросы.

## Границы версии

NPC доступен **в одиночном мире и у хоста**. Подключившийся клиент не создаёт NPC на чужом или выделенном сервере. У NPC собственные игровые данные и надгробие; вход в другой мир не переносит инвентарь. Удалённого NPC нельзя пересоздать, если его область не загружена: вернитесь к сохранённому месту.

Из общего каталога 41 действия NPC объявляет **38** (меньше при выключенном бое). Строительство, ремонт строений и самостоятельный сон через кровать в 0.7 недоступны: прежние реализации зависели от камеры/интерфейса локального игрока. NPC не мешает хосту пропускать ночь. Крафт/улучшение и ремонт выполняются без окна игрока с проверкой ресурсов и станции; особые рецепты с выбором одного ингредиента пока отклоняются. Сундук должен быть доступен NPC и принадлежать сетевому хосту; открытый человеком сундук получает приоритет. Рыбалка, торговля и корабельный автопилот не реализованы; телепортация NPC через порталы запрещена.

Сборка использует ссылочные библиотеки **Valheim 0.221.4**. Автотесты, Linux/Windows CI и запуск упакованной службы проверяют код и протокол, **игровой запуск Valheim 1.0.21 здесь недоступен**. Жизненный цикл NPC, физика, внешний вид и кооператив требуют проверки в игре по [сценариям](docs/testing.md).

## Разработка

Python 3.12, .NET SDK из `global.json`, Node.js для дополнительного веб-интерфейса:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install --require-hashes -r bridge/requirements-dev.txt
PYTHONPATH=bridge/src .venv/bin/python -m pytest bridge/tests -q
.venv/bin/python scripts/smoke_bridge.py
python3 scripts/bootstrap_mod.py
dotnet test mod/ValheimAIHelper.Tests/ValheimAIHelper.Tests.csproj -c Release -p:RestoreLockedMode=true
dotnet build mod/ValheimAIHelper/ValheimAIHelper.csproj -c Release -p:RestoreLockedMode=true
.venv/bin/python scripts/check_wire.py
```

Для внешнего моста выключите `Bridge.AutoStart`; разработческий запуск: `PYTHONPATH=bridge/src .venv/bin/python -m valheim_ai`. `start-windows.ps1` оставлен для разработки; пользователь ZIP его не запускает.

На Windows: `python -m pip install --require-hashes -r bridge/requirements-build.txt`, затем `python scripts/freeze_bridge.py`, `python scripts/smoke_frozen.py .local/frozen/ValheimAIBridge/ValheimAIBridge.exe`, `python scripts/package.py --runtime .local/frozen/ValheimAIBridge`. CI публикует ZIP после проверок обеих ОС. Игровые, Unity и BepInEx DLL не входят в архив.
