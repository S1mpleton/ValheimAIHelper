VALHEIM AI HELPER · ПРОТОТИП 0.2.0

Рядом в другом мире.

Пульт отдельного персонажа Valheim. Игра управляет правилами, ассистент выбирает действия.

Не подключён
Для игры нужен второй клиент Valheim. Войдите им в мир, затем включите управление клавишей F8.

01 · Подключение к мосту

Откройте файл .local/bridge-token рядом с пусковым скриптом и вставьте код. Это локальный код сопряжения, а не ключ GPT или Gemini.

02 · Ассистент

После выбора модели нажмите «Применить настройки».

Проверка получает карточку модели и выполняет два коротких запроса генерации. Может расходовать баланс API. Данные игры не отправляются.

20 секунд — около 3 решений в минуту. Повторы и ручные проверки тоже расходуют квоту. «Просто следовать» работает без API.

Ключ оплачивается по тарифам API. Подписка ChatGPT или Gemini не заменяет API-ключ. Состояние мира отправляется выбранному провайдеру при включении AI.

03 · Задача напарнику

Следование работает без API-ключа. Лидер задаётся по имени в конфигурации мода; без имени выбирается ближайший игрок. F9 в игре немедленно возвращает ручное управление.

Ждём наблюдение из игры…

Если «Не подключён», проверьте: игра запущена, персонаж в мире, мод включён через F8, коды сопряжения совпадают. Закройте панель F8, чтобы разрешить движение.

Последние решения

Ответы ассистента видны только здесь и в панели мода. Сообщения в игровой чат не отправляются.

    Сейчас доступны: следование, ожидание, подбор с земли, еда, экипировка и ближний бой с врагами. Строительство, добыча, крафт, сундуки, порталы и возрождение требуют человека.
