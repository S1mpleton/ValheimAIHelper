Valheim AI Helper 0.6.1 — просмотр диалога с агентом.

- Esc → Управление персонажем → Журнал → Диалог AI: фактически отправленный запрос, исходный ответ модели и отдельно результат проверки/принятый план.
- Запрос доступен во время ожидания. Видны модель, назначение и время. Ответ отображается после завершения генерации; невалидный JSON также сохраняется для диагностики.
- Страницы длинного текста, выбор последних запросов, копирование и сохранение полного обмена. Последние 8 запросов хранятся только в памяти; очистка не останавливает персонажа.
- Известные ключи/код сопряжения маскируются. HTTP-заголовки и отдельные поля размышлений не записываются. think=false для Ollama сохранён; дополнительных генераций для просмотра нет.
- В локальной веб-панели есть такой же просмотр для отдельного монитора, без открытия игрового меню.

После завершения запроса «Сохранить всё» создаёт Dialogue-…txt в BepInEx/config/ValheimAIHelper/reports. Полная инструкция — docs/dialogue.md.

Для обновления закройте игру и замените всю папку BepInEx, включая runtime/_internal. PowerShell и отдельный Python не нужны. Совместимость игрового UI с вашей Valheim требует проверки в игре; в облаке проверены сборка, C#/Python-протокол, автономная служба и веб-просмотр.
