# Результаты проверки прототипа 0.1

Проверено в облачной Linux x86_64-среде с Python 3.12.14 и .NET SDK 8.0.427:

| Проверка | Результат |
| --- | --- |
| Python-сервис, протокол, адаптеры API и обработка ошибок | 45 тестов пройдены, без пропусков |
| C#-проверки допустимости игровых действий | 17 тестов пройдены, без пропусков |
| Сборка плагина против ссылочного API Valheim 0.221.4 | Успешна, без предупреждений и ошибок |
| Вариант сборки с явно указанным каталогом ссылочных DLL | Успешен; это также не запуск игры |
| `scripts/setup-cloud.sh` | Установка и повторный запуск прошли; восстановление по lock-файлам |
| `scripts/check.sh` | Python, C#, сборка мода, проверка JavaScript прошли |
| `scripts/smoke_bridge.py` | Отдельный HTTP-процесс: готовность, панель, сопряжение, наблюдение, следование, стоп |
| Chromium, настоящий интерфейс | Неверный и верный код сопряжения, смена провайдера, следование без AI, стоп, отсутствие ключа, имена объектов как текст |
| Размеры интерфейса | Проверены 1280×1100 и 390×844, горизонтального переполнения нет |
| Python-зависимости для Windows/Python 3.12 | Бинарные пакеты скачаны с проверкой закреплённых хешей |

В тестах адаптеров используются **подставные HTTP-ответы** OpenAI/Gemini, а в браузерной проверке — **тестовые игровые снимки**. Никаких платных запросов к моделям не выполнялось. Тестовые HTTP-процессы остановлены; их состояние не выдаётся за подключённую игру.

**Не проверено:** запуск PowerShell-установщика на Windows, загрузка мода в реальном Valheim, навигация и бой внутри мира, смерть/сохранение под управлением мода, действующие ключи и модели на аккаунтах пользователя. Это обязательные следующие проверки по `testing.md` перед реальной совместной игрой. Более новые версии Valheim могут требовать изменений API. GitHub Actions настроен в исходниках; удалённый запуск workflow не выполнялся.
