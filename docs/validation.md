# Проверка 0.1.4

Проверено в облачной Linux-среде:

- 84 Python-теста: протокол и HTTP API, список моделей, отдельные этапы проверки Gemini, удаление ключа до ограничения длины диагностики, 404/429 с остановкой AI, повторы 503 и интервал между AI-решениями без задержки локального следования.
- 31 C#-тест: политика действий, сериализация, нормализация и ограниченный горизонтальный ввод (в том числе вертикальные/нечисловые направления).
- Сборка плагина net48 против Valheim 0.221.4 с Harmony из закреплённого BepInEx: без ошибок и предупреждений.
- Межъязыковая проверка фактического C# JSON → HTTP Python → C# и проверка синтаксиса JavaScript.
- Отдельный HTTP-процесс: сопряжение, наблюдения, диагностика 422, следование и стоп.
- Chromium с настоящим мостом и подставным API: выбор модели, применение настроек с интервалом, остановка при 404, восстановление, трёхэтапная проверка модели, игнорирование устаревшего списка после смены ключа, мобильный интерфейс без горизонтального переполнения.

Ответы моделей подставные; платные запросы не выполнялись. Сеть, ключ и квоты пользователя не проверялись. PowerShell-установщик на Windows, настоящий Valheim, два сетевых клиента, cross-play, Harmony-перехват в игровом процессе и исчезновение рывков у наблюдателя не проверены. Совместимость с указанной пользователем Valheim 1.0.21 остаётся неподтверждённой: доступны ссылочные библиотеки 0.221.4. Сборка и численные тесты не доказывают исправление сетевого поведения; порядок игровой проверки описан в testing.md.
