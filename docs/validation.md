# Проверка 0.1.3

Проверено в облачной Linux-среде:

- 78 Python-тестов: протокол, HTTP API, модели Gemini, повторы 503, остановка после 404, безопасное различение стандартного/нестандартного ответа и проверка модели без изменения настроек.
- 25 C#-тестов; сборка плагина net48 без ошибок и предупреждений.
- Межъязыковая проверка фактического C# JSON → HTTP Python → C# и проверка синтаксиса JavaScript.
- Отдельный HTTP-процесс: сопряжение, наблюдения, диагностика 422, следование и стоп.
- Chromium с настоящим мостом и подставными ответами API: явный список, предупреждение об отсутствующем имени, однократный отказ 404 с остановкой AI, необходимость применить выбор, восстановление после смены модели, кнопка проверки генерации, игнорирование устаревшего списка после смены ключа, ширина 390 px без горизонтального переполнения.

Ответы моделей подставные; платные запросы не выполнялись. Сетевой путь и ключи пользователя не проверялись. Windows-установщик и настоящий Valheim не запускались. Архив содержит собранную DLL и обновлённый сервис; после обновления нужны проверка модели на компьютере пользователя и запуск в игре.
