# Проверка 0.7.4

Новая область проверки — каталог ItemDrop из ObjectDB, стабильные prefab/token в наблюдениях, передача каталога с подтверждением, отдельный разбор предметного поручения Ollama и ограничение допустимых действий/целей/количества. Также проверяются правила обработки штатного нажатия E для NPC и сохранение обычного взаимодействия с другими объектами. Фаза разбора имеет отдельную запись `item-intent` в диалоге AI; все запросы Ollama используют `think=false`.

Локально прошли **267 Python-тестов и 181 C#-тест**. DLL собрана без ошибок и предупреждений. Добавлены проверки каталога/экспорта, определения целей и количества, восстановления каталога после перезапуска службы, обработки E и ошибочного выбора передачи всей сумки вместо пяти камней.

С настоящей локальной **Qwen3:1.7B в Ollama, think=false**, проверены три запроса на искусственных снимках мира: отсутствующий топор → тип `AxeStone` и ответ об отсутствии; малина → `interact` подходящего куста; пять камней при одуванчике первым в сумке → `give` камней с точным количеством 5. Это проверка ответов модели на подготовленных данных, а не игровой запуск или проверка пользовательской Llama 3.2.

При ранней живой проверке Qwen ошибочно выбирала весь инвентарь вместо пяти камней. После изменения схемы и примеров добавлена отдельная модельная проверка `item-scope` для выбора `all_inventory`: при неподтверждённом выборе выполняется один повтор разбора без этой ветки. Автотест с подставными ответами проверяет исправление такой ошибки. Ограничения формата и успешные контрольные запросы не гарантируют понимания любой свободной фразы небольшой моделью.

В присланном отчёте не было записей попытки открытия инвентаря или исключения, поэтому точная причина прежнего отказа E по нему не установлена. Новый журнал разделяет нажатие, запрос, открытие и закрытие. Основной обработчик работает через `Player.Interact`; резервный использует штатную наведённую цель после обновления человека и не обрабатывает набор чата, меню или обычные сундуки.

Valheim 1.0.21 в облачной среде не запускается. Сборка против SDK 0.221.4 и автоматические проверки не подтверждают фактическое открытие GUI, переносы, физику и сохранение внутри игры. [Проверка 0.7.4 в игре](testing.md#предметы-и-открытие-инвентаря-074).

## Результаты 0.7.3

По новому отчёту добавлены регрессии завершения ответа, отсутствия повторной генерации по завершённой миссии, перевода читаемых локальных ID в исходные игровые, совпадающих имён/разного качества и отказа от буквального эха. Прошли 244 Python-теста. C#-набор содержит 166 тестов. Проверки используют подставные ответы моделей и не доказывают понимание русского любой локальной моделью на 3B.

## Изменения 0.7.2

Новая область проверки — ручной доступ человека к собственному инвентарю NPC через штатный InventoryGui, остановка автономного управления на время обмена и тихие проверки необязательных членов разных версий игры. Проверки провайдеров, протокола C# ↔ Python и упакованной службы сохраняются. Платные API-запросы для проверки инвентаря не нужны.

Локально прошли 234 Python-теста, 166 C#-тестов, фактический обмен C# → Python HTTP → C#, запуск службы отдельным процессом и проверка JavaScript. DLL 0.7.2 собрана без ошибок и предупреждений. Новые тесты проверяют доступ к сумке, потерю владения/готовности, границы расстояния и повторное чтение отсутствующих членов разных версий игры. Нативные переносы вещей проверяются отдельно внутри игры.

Valheim 1.0.21 в облачной среде не запускается. Сборка против SDK 0.221.4 и автоматические проверки не подтверждают поведение GUI, экипировки, переноса вещей, смерти и сохранения в настоящей игре. [Сценарии для проверки версии 0.7.2](testing.md#инвентарь-и-предупреждения-072).

# Проверка 0.2.0

Проверено в облачной Linux-среде:

- 90 Python-тестов: протокол и HTTP API, OpenAI/Gemini модели и проверки, low reasoning для gpt-6-luna и Gemini 3.8, удаление ключей из ошибок, 404/429/503 и тайм-ауты.
- 41 C#-тест: политика действий, сериализация, ограниченный ввод, безопасный loopback-адрес и чтение статуса игровым интерфейсом.
- Сборка плагина net48 против Valheim 0.221.4: без ошибок и предупреждений.
- Межъязыковая проверка фактического C# JSON → Python HTTP API → C#: решения, а также DTO новой игровой панели для настроек, списка OpenAI, проверки модели и стопа. Проверяются обе формы успешного ответа API: настройки с key_present и команды с revision.
- Отдельный HTTP-процесс: сопряжение, наблюдения, диагностика 422, следование и стоп. Синтаксис дополнительной веб-панели проверен Node.

Живые проверки официальных API с разрешения пользователя:

- OpenAI gpt-6-luna: HTTP 200, простой ответ OK за 1,6 секунды. Через настоящий адаптер и схему действий: валидный wait и «Связь работает» за 4,2 секунды.
- Gemini gemini-3.8-flash: список и карточка модели HTTP 200. Обычный короткий запрос не ответил за 30 секунд. MINIMAL был отклонён HTTP 400; LOW принят, но генерация вернула HTTP 503 с сообщением о высокой нагрузке.
- Реальные игровые данные не отправлялись. Ключи использовались только в памяти процессов и не включены в код/пакет. Остальные тесты используют подставные HTTP-ответы.

Не проверены: настоящий процесс Valheim, отрисовка кнопки и панели, мышь/клавиатура внутри Unity, навигация игрового меню контроллером, сетевое движение и совместимость с Valheim 1.0.21. Для этих проверок требуется установленная игра; сборка и межъязыковые тесты не заменяют игровой запуск. PowerShell-установщик не запускался против установленной игры. В Windows CI добавлена проверка синтаксиса пусковых скриптов.
