# Valheim AI Helper 0.7.0 — один клиент + NPC

Помощник теперь создаётся отдельным NPC в вашем одиночном мире или на клиенте-хосте. Второй клиент/Steam-аккаунт не требуется. Esc → «Управление персонажем» → «Персонаж» → «Создать / найти NPC». По умолчанию имя Гоша. Ваш персонаж остаётся под вашим управлением.

- Отдельные инвентарь, игровой профиль и сохранение NPC в мире; повторное создание проверяет и неактивные области. При смерти — собственное надгробие, без возрождения/изменения профиля человека.
- Только точная фраза «следуй за мной» обходит модель. «Гоша, пошли», «пойдём», «за мной» и произвольные синонимы разбирает AI. Стоп/F9 немедленны.
- Передача точного количества из нескольких одинаковых стопок, всех выбранных предметов или всего неквестового инвентаря. NPC подходит к актуальной позиции получателя и сбрасывает вещи рядом; результат проверяется по инвентарю. Частичная выдача не повторяет исходное количество.
- Повторный поиск пешего маршрута, варианты подхода, проверка этажей/наклона/прогресса, ограниченное восстановление при застревании. Телепортации к лидеру нет.
- Контейнеры, крафт, улучшение и ремонт NPC работают без открытия инвентаря человека. Новое явное поручение заменяет старые ожидающие; дубль не перезапускает модель.
- Сохраняются Ollama с think=false/выгрузкой прошлых моделей, измерение скорости и просмотр полного диалога AI в журнале.

Из каталога NPC объявляет 38 действий. Строительство, ремонт строений и самостоятельный сон через кровать пока исключены: старые реализации зависели от локальной камеры/интерфейса. NPC не мешает хосту пропускать ночь. Особые рецепты с выбором одного ингредиента отклоняются; сундуку нужны доступ и сетевое владение хостом. Подключившийся клиент не создаёт NPC на чужом/выделенном сервере.

Установка: закрыть игру, заменить всю папку BepInEx из ZIP, сохранить runtime/_internal, удалить старую отдельную копию DLL. PowerShell/Python/браузер для обычного запуска не нужны. Персонаж второго клиента и его вещи автоматически не импортируются.

Проверки CI: Python, C#, реальный обмен C#↔HTTP↔модели на подставных ответах, DLL, Linux/Windows, запуск упакованной службы без исходников/Python, архив и SHA256. Платных запросов нет. **Игра Valheim 1.0.21 в среде сборки не запускается; физика, вид NPC, сохранение и кооператив требуют проверки в игре.** Сборка по ссылкам 0.221.4.
