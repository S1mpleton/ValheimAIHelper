Valheim AI Helper 0.6.0 — предметы, обратная связь и скорость локального AI.

- Переключение Ollama выгружает все остальные ранее загруженные модели на выбранном локальном сервере через /api/ps и keep_alive=0. Файлы моделей остаются. Смена модели отменяет старую генерацию; одинаковая модель остаётся загруженной.
- В игре показаны время ожидания, полное время запроса и скорость генерации; журнал/отчёт содержат загрузку, обработку входа и выходные токены. Ошибочный план отмечается как ошибка, даже если модель быстро сгенерировала JSON.
- Обзор загруженных выпавших ItemDrop расширен с 20 до 128 метров и с 18 до 80 стопок. Передаются количества, вес, позиции и сведения о сокращении; Ollama не удаляет дальние стопки из полученного снимка.
- Добавлен give: подойти к игроку и сбросить рядом точное количество из личного инвентаря. Улучшены pickup/drop: штатное получение владения, проверка места/веса, подтверждение изменения стопки. Завершённая передача не повторяется в следующем цикле.
- Для локальных моделей схема разрешает реальные цели нужного типа: give получает игрока и ID сумки, pickup — ID выпавшей стопки. Неиспользуемые аргументы не генерируются. Количество и необходимые аргументы обязательны.
- Обращение по имени подтверждается до ожидания модели и становится приоритетным. В чате появляются начало действий, подтверждённые результаты операций и причины блокировки/ошибок. Модельные обещания больше не подменяют подтверждение выполнения задания.
- Вместо общего «недопустимое действие; персонаж остановлен» показываются шаг и причина. После трёх подряд недопустимых планов AI останавливается. think=false сохраняется для всех генераций Ollama.

Установка: закрыть игру и заменить всю папку BepInEx из архива, включая runtime/_internal. PowerShell и отдельный Python не нужны. В игре: Esc → Управление персонажем → Подключение AI → Ollama → модель → Проверить → Сохранить → Включить AI. Перед переключением освобождается память и от других ранее загруженных в этот Ollama моделей.

Полный каталог 41 действия, их состав, команды и сценарии проверки — docs/actions.md. Настройка/показатели скорости — docs/ollama.md.

Проверены настоящий Ollama 0.40.16: выгрузка двух загруженных моделей и qwen3:1.7b с think=false, корректная передача пяти камней. Проверки C#/Python проходят на Linux и Windows; Windows-служба проверяется без установленного Python. В облаке нет работающей Valheim 1.0.21, поэтому реальное движение/сеть и UI внутри игры здесь не проверены.
