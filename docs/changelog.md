# 0.1.2

- Кнопка «Получить модели Gemini»: авторизованный запрос списка с пагинацией, фильтр `generateContent`, выбор через подсказки и ручной ввод. Ключ передаётся заголовком API, не попадает в URL и ответы; загрузка списка не меняет режим управления и не сохраняет новый ключ.
- Лимиты: 30 секунд на попытку API, 100 секунд на решение в мосте, 110 секунд в моде и браузере; индикатор подключения учитывает до 180 секунд между снимками.
- HTTP 503: максимум три попытки с паузами 2/4 секунды. После исчерпания повторов решений — 15 секунд без новых запросов. Персонаж ждёт; ошибки не раскрывают тело ответа API. Другие HTTP-ошибки не повторяются.
- Регрессии: страницы списка моделей, авторизация, сохранённый/временный ключ, повторы, восстановление и пауза после 503. Существующая отмена устаревших решений сохранена.

Обновляйте DLL и мост вместе. Реальный запуск Windows/Valheim и запросы с платными API-ключами в облаке не проверялись.

# 0.1.1

Исправления после сообщения о загруженном моде, HTTP 422 и отсутствии реакций:

- В 0.1.0 отрицательная выносливость воспроизводит HTTP 422 (`actor.stamina: greater_than_equal`). Теперь нативный остаток ниже нуля нормализуется в наблюдении до нуля; пустые стеки инвентаря игнорируются. Игровые значения не меняются.
- Отправка снимков и чтение ответов переведены на явный C# `DataContractJsonSerializer`, общий с межъязыковой проверкой. Имена полей, Unicode, дробные координаты, массивы и булевы значения проверяются между C# и Python.
- Мод различает отсутствие соединения, неверный код сопряжения, конфликт сессии и отклонённый снимок. HTTP 422 больше не называется «мост недоступен»: показывается безопасный путь поля. Сообщение не пропадает из-за открытой панели F8.
- Веб-панель показывает ошибки снимков и не позволяет включать действия, пока нет корректного наблюдения. Это исключает ложное впечатление, что выбранный режим уже выполняется.
- Добавлено действие `move` для команды «Иди вперёд»: максимум 3 секунды / 4 м по встроенному пешему маршруту. Ранее такой команды не было. Старым модам без объявленной поддержки она не отправляется.
- Упаковщик берёт номер версии из проекта DLL, чтобы имя архива соответствовало сборке.

**Точная причина 422 на присланном скриншоте не установлена:** там отсутствует тело ответа сервиса. Исправлен воспроизводимый отказ на нативных показателях и добавлена диагностика остальных причин. Исправление движения нужно проверить в настоящем Valheim; игра в облачной среде не запускается.

Для обновления нужны **и DLL, и сервис** из полного архива 0.1.1. Закройте игру/старый сервис, запустите новый `start-windows.ps1`, затем игру. Убедитесь, что F8 показывает 0.1.1, обновите браузер, дождитесь имени персонажа, закройте F8 и проверьте «Просто следовать» без API-ключа.
