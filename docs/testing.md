# Проверка 0.7.1 и диагностика

## Автоматически

- Python: провайдеры на подставных ответах, 503/тайм-ауты/квоты, Ollama think=false/выгрузка моделей, фоновые планы, отмена, чат, точная/массовая передача и реальные исходы шагов.
- C#: запрет управления человеком/чужим/мёртвым NPC, допуск действий по снимку, резерв нескольких стопок, защита квестовых вещей, commit только один раз, частичный отказ/уход получателя, этажи/наклон/повторы навигации, одна быстрая фраза следования, протокол/UI/маскировка ключей.
- Wire probe: настоящий C#-сериализатор → Python HTTP → подставная модель → C#-декодер/политика. Сверяется общий каталог 41 действия и ограниченный набор NPC. PE-проверка запрещает прямые вызовы защищённого GetRightItem.
- HTTP smoke: запуск службы, сопряжение, авторизация, ошибки схемы, следование/стоп.
- Frozen smoke: упакованный EXE запускается без каталога исходников/Python; проверяются HTTP, статика, авторизация и версия. На Windows — дескриптор родительского процесса.
- GitHub CI проверяет Linux и Windows, собирает DLL/Windows ZIP и сверяет SHA256 перед релизом. Платных API-запросов нет.

**Среда проверки не запускает Valheim.** Эти проверки не подтверждают фактическое создание/отрисовку NPC, физику, смерть/сохранение и сетевое поведение на Valheim 1.0.21. Ссылочный SDK — 0.221.4; при несовместимости методов создание блокируется, журнал сохраняет стек.

## В игре

1. Закройте игру, замените весь каталог плагина из ZIP, включая runtime/_internal, удалите старую отдельную DLL. Запустите **один клиент** своим обычным персонажем. PowerShell/Python/браузер не нужны.
2. Войдите в свой тестовый мир либо запустите мир хостом. Esc/F8 → «Персонаж» → «Создать / найти NPC». Должен появиться отдельный Гоша с пустой сумкой, а ваш персонаж продолжить обычное управление.
3. Нажмите «Следовать». Ходите, прыгайте, вращайте камеру и пользуйтесь хотбаром человеком. NPC движется независимо; F9 останавливает только его. Набор чата/инвентарь человека не должен обрывать связь NPC; настоящая пауза одиночной игры останавливает физику.
4. Настройте Ollama и включите AI. Сравните точное «следуй за мной» и «Гоша, пошли»: второе должно попасть в сохранённый запрос AI. При долгом ответе UI показывает время, F9 отменяет.
5. Выполните [проверки предметов/путей](actions.md): 5 + 3 камня → передать 7, все камни, весь инвентарь, движущийся получатель, недоступный путь, квестовая вещь. Сопоставьте землю, сумку NPC, чат и отчёт.
6. Откройте свой инвентарь во время операций NPC. Он не должен закрываться, менять выбранный рецепт или получать вещи NPC. Проверьте сундук: доступ NPC/хост-владение, закрытое содержимое не видно; открытый человеком контейнер получает приоритет.
7. Проверьте крафт/ремонт с достаточными и недостаточными материалами/укрытием/уровнем станции. Строительство/ремонт строений/сон не должны выдаваться AI как доступные действия. При невозможном поручении нужна причина.
8. Сохраните и перезайдите. NPC должен остаться с теми же вещами; повторное создание — найти того же. Отойдите из области и нажмите создание: повторный NPC не должен появляться, окно покажет сохранённое место.
9. В тестовом мире проверьте смерть NPC: отдельное надгробие и вещи, человек не умирает/не возрождается; новый NPC — только явно и с пустой сумкой. Проверьте также сон человека: NPC не должен блокировать пропуск ночи.
10. С другим официальным клиентом проверьте видимость движения NPC, смену зон/лидера и чат «Только лидер / Все игроки». У подключившегося клиента создание на чужом мире должно отказать с понятным сообщением.
11. Проверьте разные разрешения/GUI scale, подсветку пункта Esc, вкладки и F8-резерв. Журнал/Диалог AI должны копироваться и сохраняться без ключей.

## Что отправить

Esc/F8 → «Журнал» → «Копировать отчёт» и **«Диалог AI → Сохранить обмен»**. Первый показывает версии, человеческого персонажа/NPC, планы, инвентарь и исключения; второй — фактический запрос, сырой ответ и проверку. Файлы отчётов — `BepInEx/config/ValheimAIHelper/reports`. Укажите поручение, результат на земле/в сумке и роль хост/подключившийся клиент. Ключи присылать не нужно.

Служба не стартует — проверьте полный runtime из ZIP. «NPC в незагруженной области» — вернитесь к указанному месту, автоматического призыва нет. Нет пути — NPC останавливается после ограниченных попыток, телепортации нет. 404/429 — полный ответ провайдера в журнале; 503 — ограниченные повторы и пауза. Медленная/слабая модель — время, фазы и токены/сек в «Журнал»; скорость не гарантирует правильное понимание задачи.

## Регрессии 0.7.1

- Локальный человек «Гоша», старый LeaderName «Бъёрн»: по умолчанию выбран человек этого клиента. Явный удалённый лидер при исчезновении не подменяется одноимённым.
- Наведение по Esc не переустанавливает кнопку. Откройте каждую вкладку дважды, измените масштаб; проверьте `ui-time`, журнал и его диалог.
- Сопровождение проходит переходы «подойти → удерживать → снова идти», не дрожит около порога и не требует генерации каждые 4/20 секунд. Новый чат должен обрабатываться.
- Ошибка предыдущего пути не отменяет блок/отступление при нападении. Пауза одиночной игры не исчерпывает бюджет шага.
- Пустая сумка, рядом выпавший камень/гриб и дерево: pickup работает без инструмента, gather не предлагается. Гриб-растение имеет interact; выпавший урожай затем pickup. Наличие/качество/поломка кирки изменяют доступность mining.
- Автотесты дополнительно проверяют 10 000 повторных обновлений UI с одним поиском типа и одним изменением подписи, частоту native-query gate, связанный private float-tick и новые правила инструментов. Реальная скорость UI/физика требуют игрового теста.
