# Проверка и устранение проблем

## Что можно проверить без Valheim

- Python-тесты: протокол, оба формата API на подставных HTTP-ответах, ошибки API/таймаут, сокрытие ключей, локальное следование, сессии, устаревшие решения, отмена при «Стоп», интерфейс и HTTP-ограничения.
- C#-тесты: политика целей и версий, ограничения длительности, отдельное разрешение боя, запрет атак игроков и выдуманных действий.
- `scripts/smoke_bridge.py`: реальный запуск сервиса отдельным процессом, готовность HTTP, страница панели, сопряжение, снимок, следование, остановка. Сетевых вызовов GPT/Gemini нет.
- `scripts/check_wire.py`: настоящий JSON из общих C# DTO и сериализатора проходит Python HTTP-проверки; ответы следования и подставного AI-движения читаются C#-декодером и проверяются политикой.
- Сборка плагина против ссылочных DLL Valheim и проверка JavaScript. Это не запуск игры.

Платные API-вызовы без предоставленного пользователем ключа не выполняются. Успешный тест с подставным ответом подтверждает адаптер, но не доступность выбранной модели, квоту или совместимость её формата на реальном аккаунте.

## Первая игровая проверка (пока не выполнена в облаке)

Используйте отдельного нового персонажа и тестовый мир, прежде чем переносить в основное сохранение. Начните с отключённого боя.

1. Запустите сервис, откройте панель, выполните сопряжение. `GET /health` должен отвечать `ok`.
2. Запустите второй Valheim с BepInEx. В `BepInEx/LogOutput.log` должна быть запись `AI Helper loaded. Control is OFF`.
3. Создайте персонажа, войдите в кооперативный мир, подойдите к вашему основному персонажу. Убедитесь, что имя лидера задано верно или рядом нет других игроков.
4. Через F8 включите AI для этого персонажа. Первый снимок должен показываться в браузере, режим — «стоп».
5. Нажмите «Просто следовать», пройдите 10 м по ровной земле. Проверьте нормальную скорость, коллизии и остановку на дистанции около 3 м. Попробуйте повернуть камеру клиента напарника: направление движения не должно зависеть от неё.
6. Нажмите F9. Управление немедленно должно вернуться клавиатуре и мыши. Включите мод заново: до новой команды он должен ждать.
7. Отключите мост во время следования: движение должно прекратиться максимум через срок действия команды (3 секунды). Откройте инвентарь/меню: действия должны прекратиться.
8. Добавьте действующий API-ключ в панели и простую задачу. Проверьте запись источника `openai` или `gemini`; `fallback` означает ошибку, а не успешный ответ. Попробуйте оба провайдера по отдельности при наличии ключей.
9. Вручную выбросьте камень/еду рядом. Задайте подобрать предмет: он должен перейти из мира в инвентарь только один раз. Попросите съесть еду: количество должно уменьшиться штатным образом. Экипировка не должна создавать новые вещи.
10. Если включаете ближний бой, проверьте его на одном слабом противнике вдали от построек. Урон и расход выносливости должны быть обычными. Не оставляйте первый запуск без присмотра.
11. Проверьте смерть, возрождение, выход и повторный вход: профиль сохраняет сама игра; контроллер после смерти/выхода должен остаться выключенным, а вещи — следовать штатным правилам смерти вашего мира.

Пока эти пункты не пройдены на установленной версии игры, не считайте игровое поведение подтверждённым. Сборка против API `0.221.4` не гарантирует совместимость с более новой версией. Используйте `scripts/build-mod.ps1 -GameDir ...` для проверки локальных библиотек.

## Если что-то не работает

| Симптом | Действие |
| --- | --- |
| F8 ничего не открывает | Проверьте запуск с BepInEx и расположение нашего DLL. Посмотрите `LogOutput.log`. Не устанавливайте две копии плагина |
| Мод не загружается / MissingMethodException | Версия игры изменила API. Соберите против установленных DLL; может требоваться адаптация исходников |
| Панель ждёт игру | Сначала войдите в мир и включите мод F8. Проверьте процесс моста и одинаковый порт |
| HTTP 401 | Код мода не совпадает с `.local/bridge-token`. Закройте игру и повторите пусковой скрипт с `-GameDir` |
| HTTP 409 | Устаревший снимок или другой персонаж уже занял мост. Отключите другого, подождите 30 секунд; отдельным персонажам нужны отдельные порты |
| Есть снимок, персонаж стоит | Новая сессия начинает с «стоп». Нажмите «Просто следовать» или «Включить AI». Закройте игровую панель F8 |
| HTTP 422, панель ждёт наблюдение | Обновите DLL и Python-сервис до 0.1.1 вместе, закройте старое окно сервиса, перезапустите игру и обновите браузер Ctrl+F5. В панели персонажа теперь указан путь отклонённого поля; эту строку можно прислать для диагностики без ключей |
| Команда «Иди вперёд» | Доступна с 0.1.1 в AI-режиме, до 4 м / 3 секунд за действие. Сначала проверьте «Просто следовать» без API. Для движения панель F8 должна быть закрыта |
| Лидер не виден | Проверьте имя `LeaderName`, расстояние до 60 м и выбранный при включении персонаж. Мир вне загруженной области не отслеживается |
| Маршрут не найден | Дверь, вода, прыжок, портал, разгруженная область или недоступная сетка навигации. Проведите вручную через F9 |
| API 401/403 | Ключ отклонён или нет доступа к модели/региону. Используйте API-ключ соответствующего сервиса |
| API 404 | Указанная модель недоступна на этом аккаунте или больше не существует |
| API 429 | Квота, баланс или лимит запросов; увеличьте интервал или измените тариф |
| «Недопустимое действие» | Модель вернула неверный JSON/цель либо неподдерживаемую команду. Задайте более простую задачу |
| Атака отклонена | Бой выключен, противник не нападает, используется дальнобойное оружие или мало здоровья/выносливости |

При сообщении об ошибке приложите версию Valheim, версию BepInEx и строку ошибки. Не публикуйте API-ключ, `Bridge.Token`, полный файл конфигурации или данные аккаунта.


Проверка 0.1.4 с двумя клиентами и cross-play:

1. На клиенте напарника проверьте версию 0.1.4 в F8 и строку `Valheim version:` в BepInEx/LogOutput.log.
2. Включите «Просто следовать» без AI, закройте F8 и сравните движение в окнах напарника и наблюдателя. Проверьте ровный участок, склон, остановку лидера и F9. Сетевая проверка должна подтвердить отсутствие откатов и ухода под землю у наблюдателя.
3. Проверьте F9 и меню, смерть/переподключение; управление не должно применяться к чужому или не принадлежащему клиенту объекту.
4. Проверьте Gemini кнопкой диагностики: при 404 запишите полный текст этапа и пояснение Google без ключа. При 429 проверьте квоты конкретной модели/проекта. Для бесплатного API используйте увеличенный интервал между решениями и учитывайте дневной лимит; два диагностических вызова генерации тоже его расходуют.


Проверка игрового интерфейса 0.2.0 на установленной игре:

1. После обновления проверьте пункт «AI-ПОМОЩНИК» в Esc и резервный F8. Повторное открытие меню не должно создавать дубликаты кнопки или открывать список игроков вместе с панелью.
2. В панели ввод задачи/ключа не должен двигать персонажа или камеру. Проверьте Esc/«Назад», F8, F9 и паузу одиночного режима.
3. «Следовать» работает без ключа и без браузера. AI сначала сохраняет подключение и дожидается первого снимка, затем выполняет задачу. Проверьте OpenAI/Gemini, список моделей, маскировку и смену ключа, остановку и повторное включение.
4. Закройте службу, убедитесь в понятном сообщении в игре, запустите start-bridge.ps1 без закрытия Valheim и повторите соединение.
5. Проверьте 1280×720 и более высокий экран, сворачивание подключения и прокрутку длинной ошибки. Такие проверки требуют настоящего игрового процесса; облачные тесты протокола их не заменяют.
