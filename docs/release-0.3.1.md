Valheim AI Helper 0.3.1 — управление из игры и чата лидера.

- Esc → «Управление персонажем»: окно со штатными элементами оформления Valheim, вкладками персонажа, AI и журнала.
- Команды от выбранного лидера: !ai следуй, !ai стоп, !ai статус, !ai <задача>. Мод лидеру не нужен.
- Непрерывное управление между ответами API: следование, бой/прицеливание, блок/уклонение/отступление, еда/экипировка, подбор/растения/двери. Модель получает расширенные наблюдения и результаты шагов и составляет короткие планы.
- Бой, автоматическая еда и чат включаются в панели; старое значение AllowCombat сохраняется.
- Windows-служба включена в архив, запускается и завершается модом. Python, PowerShell и браузер для обычного запуска не нужны.
- Журнал с копированием/экспортом отчёта; ключи маскируются.
- Остановка службой после ошибки API возвращает ручное управление. Ответ от предыдущей команды не может отменить новую команду из чата.

Установка: закрыть игру и прежний мост; скопировать папку BepInEx из ZIP в каталог Valheim. Сохранить runtime и _internal. Старую отдельную BepInEx/plugins/ValheimAIHelper.dll удалить, если она осталась. BepInExPack Valheim устанавливается отдельно. Затем войти в мир, F8, выбрать лидера и настроить AI.

Это экспериментальный сценарий «следовать → сражаться → выживать» с отдельным клиентом помощника. Крафт, стройка, шахты, сундуки, лодки и возрождение ещё не реализованы. Сборка использует ссылочные библиотеки Valheim 0.221.4; GUI, чат и бой требуют проверки в установленной игре. Автотесты и запуск упакованной службы не заменяют тест в Valheim.

Вложения: готовый Windows ZIP и SHA256. Исходники доступны по тегу релиза.
