# Valheim AI Helper 0.7.2

Инвентарь NPC можно открыть прямо в игре: **подойдите и нажмите E** либо выберите **Esc/F8 → Персонаж → Инвентарь NPC**. Штатное окно показывает вещи человека и помощника, позволяет класть и забирать предметы, делить стопки, складывать одинаковые вещи и забирать всё. Модель и API-ключ для обмена не нужны.

Используется собственный инвентарь NPC с сохранением количества, качества и данных предметов. Перемещаемое снаряжение сначала снимается с NPC. Перед обменом NPC останавливается и ожидающий запрос AI отменяется; после закрытия снова включите следование или AI. Открытие доступно человеку на клиенте-хосте в пределах 3,5 м; при удалении более 4 м, смерти или выходе из мира обмен закрывается.

Убран оставшийся флуд HarmonyX при поиске необязательных полей меню разных версий игры. Такие проверки выполняются без предупреждений и кешируют результат, включая отсутствие члена. Большая часть предупреждений `AccessTools.Property` из присланного отчёта уже была устранена в 0.7.1; остальные предупреждения Harmony не скрываются.

Закройте игру и замените папку **BepInEx** из нового ZIP целиком в пределах каталога плагина, включая `runtime/_internal`. Удалите старую отдельную `BepInEx/plugins/ValheimAIHelper.dll`, если она осталась. Python, PowerShell и второй клиент не нужны. В журнале запуска должна быть версия 0.7.2.

Прошли 234 Python-теста, 166 C#-тестов, проверка фактического C# ↔ HTTP обмена и запуска службы. DLL собрана без ошибок и предупреждений. **Valheim 1.0.21 в среде разработки недоступен:** отрисовка окна, фактические переносы, сохранение и кооператив требуют [проверки в игре](https://github.com/S1mpleton/ValheimAIHelper/blob/main/docs/testing.md). Ссылочный SDK — 0.221.4; прежние ограничения NPC и набора действий сохраняются.
