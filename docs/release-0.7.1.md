# Valheim AI Helper 0.7.1 — меню, непрерывное следование и подбор без кирки

Исправления по отчётам 0.7.0:

- Esc больше не переобходит всю иерархию меню при наведении/обновлении навигации. Типы и свойства UI кэшируются; подписи не перестраиваются без изменений. Вкладки подключения и журнала создаются при первом выборе, остальные скрытые страницы не обновляются. В журнал добавлено время открытия окна/создания вкладки (`ui-time`).
- Для одного клиента лидер по умолчанию — настоящий локальный игрок. Старое имя лидера от второго клиента не ломает этот режим. Явно выбранный удалённый лидер сохраняется по игровому ID; совпадение отображаемого имени не меняет личность. Совпадение имени NPC с вашим отмечается в окне.
- Follow — непрерывный навык с удержанием дистанции 2,5–4 м, отслеживанием лидера до 128 м в загруженной области, ограниченным поиском/повторами и сохранением рабочего маршрута при перестроении. Пустой ожидающий путь больше не вызывает частые повторные запросы. Телепортации нет.
- Результат старой задачи (`blocked/success`) больше не отменяет рассчитанную защиту/отступление. Рефлексы сохраняют результат основного поручения; настоящий стоп и истёкшая связь по-прежнему прекращают ввод. Ожидающие ответы имеют трёхсекундную аренду, игровая пауза не расходует бюджет шага.
- Выпавшие вещи, растения и добываемые ресурсы разделены по реальным механикам. Обычный Destructible не делает гриб/декорацию ресурсом для кирки. Без подходящего инструмента gather исключён из локальной схемы; имеющийся инструмент экипируется перед добычей. Pickup не требует инструментов.
- Возвращаемый Pickable.Interact флаг анимации больше не считается доказательством успеха/отказа: проверяются фактический сбор и появление вещей.
- Для Ollama — один игровой навык за ответ; путь/поворот/подход остаются локальными. Устойчивый follow не запускает модель каждые несколько секунд, но новые сообщения продолжают обрабатываться. think=false и выгрузка предыдущих моделей сохранены.

Установка: закрыть игру и заменить всю папку BepInEx из ZIP. Другие папки рядом с valheim.exe не нужны. Проверка в игре: локальный игрок должен отображаться лидером; NPC желательно дать отличающееся имя. Сначала «Следовать», затем AI и поручения «подбери выпавший камень», «сорви гриб». Для растения возможны interact и последующий pickup выпавшего урожая.

Проверены C#/Python, обмен C#↔HTTP↔модели, сборка DLL и упакованная служба. Настоящая локальная Qwen3 1.7B с think=false выбрала follow и pickup для двух контрольных запросов; это не гарантирует поведение всех моделей/всех формулировок. **Valheim 1.0.21 здесь не запускается: физика, UI и кооператив требуют проверки в игре.** SDK 0.221.4, архитектура одного клиента + NPC и прежние ограничения 38 действий сохраняются.
