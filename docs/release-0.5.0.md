Valheim AI Helper 0.5.0 — локальные модели Ollama без облачных токенов.

- В игровых настройках появился провайдер Ollama: локальный адрес, список установленных моделей, проверка JSON-плана, сохранение и работа через обычный чат.
- API-ключ не требуется. Модели с тегами/пространствами имён поддерживаются. Ollama и веса моделей не включаются в ZIP и не скачиваются модом автоматически.
- Все запросы генерации используют think=false, stream=false и JSON schema. Обязательный reasoning не заменяется режимом low: выбирается совместимая модель.
- Планировщик, 40 игровых действий, проверка свежих целей, доступ «Только лидер/Все игроки», F9 и экспорт журнала работают с локальным провайдером.
- Для холодной/CPU-модели ожидание увеличено до 300 секунд, UI — 310; снимки не блокируются медленным планом. Стоп отменяет и долгую проверку модели.
- Аргументы действий обязательны в JSON-схеме, включая количество предметов. Планировщик ждёт подтверждения шагов с побочными эффектами и отбрасывает ответы по состоянию до уже завершённого действия.
- Локальный HTTP-клиент отделён от облачного, принимает только loopback-адрес и не передаёт облачные ключи. Облачные модели/перенаправления и скрытый платный fallback не используются.
- Исправлен учёт готовности провайдера: агент и разбор чата могут работать без подставного ключа.

Установка: закрыть игру и заменить всю папку BepInEx из архива, сохранив runtime/_internal. Запустить Ollama на том же ПК и загрузить текстовую модель. В игре: Esc → Управление персонажем → Подключение AI → Ollama → Получить модели → Проверить → Сохранить. Затем включить AI и давать поручения в чате.

Подробности и ограничения — docs/ollama.md. Качество и скорость зависят от модели и оборудования; валидный JSON не гарантирует правильную тактику. Реальная Valheim 1.0.21 в облаке не запускается.

Проверен настоящий Ollama 0.40.16 с qwen2.5:3b на CPU: C#-снимок со всеми 40 действиями → сброс ровно 5 камней → C#-декодер/проверка. think=false, облачные запросы отсутствуют. Автоматические проверки используют локальный HTTP-стенд без загрузки моделей; Windows EXE проверяется отдельно.
