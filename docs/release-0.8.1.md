# Valheim AI Helper 0.8.1

Обновление исправляет обработку новых поручений во время работы NPC, повторные задачи, наблюдение предметов и открытие инвентаря.

- **Обращение без имени.** Разрешённый чат единственного человека в мире направляется NPC напрямую. При нескольких людях короткий классификатор определяет адресата, а явное имя NPC проходит без него. Исходная просьба передаётся AI целиком, без выбора ответа-эха вместо действия. Человек и NPC остаются разными участниками, даже если обоих зовут Гоша.
- **Продолжение прежней работы.** Новое обращение не ставит пул на паузу. Готовый проверенный план применяется по свежему снимку; уже начатая передача получает результат игры до переключения. Ошибка нового плана сохраняет прежние задачи.
- **Отмена и отсутствие дублей.** Поручение может изменить существующую задачу, например отменить сбор малины и оставить следование. Одинаковые задания объединяются, включая дубли из сохранений 0.8.0. Названия соответствуют реальным типам задач. Разные задания сбора одного приоритета получают ход после подтверждённого шага.
- **Предметы через E.** Наблюдение включает загруженные `ItemDrop`, `Pickable` и `PickableItem` до 128 м с общим ограничением 80 целей и сохранением разных типов. Топор или одуванчик через E не принимается за залежь, требующую кирки. В отчёт добавлен отдельный список `E collectibles`.
- **Инвентарь.** E ставит открытие в очередь вне обработчика взаимодействия. Предпочтительно используется штатное окно с сумкой человека и NPC. Если игровой адаптер недоступен или окно не стало видимым, включается резервный обмен с двумя сетками, иконками и количеством. В резервном окне Shift + нажатие переносит стопку. Экипировка NPC отмечена бело-серым; оформление человека сохраняется.
- **Каталог по запросу AI.** Сначала передаются только наблюдаемые типы предметов. При необходимости модель запрашивает `catalog_queries`; полный игровой каталог не прикладывается к каждой просьбе.
- **План и приоритеты выбирает AI.** Для всех провайдеров используется полный формат задач: приоритет новой задачи обязателен, состав и зависимости задаёт модель. Нативных приоритетов по типу работы, автоматического повышения следования и специальных шаблонов для Gemma 1B нет. Удалены готовые задания с малиной; `think=false` сохраняется. Слабая модель может ошибиться в плане — это отображается как ошибка, а не скрывается заменой её решения.

Проверки установленного Valheim 1.0.21 в среде разработки недоступны. Поэтому открытие окна, цвет отметок и движение нужно проверить в игре. Автотесты и живые запросы модели описываются в [результатах проверки](validation.md); они не заменяют игровой запуск.

Для обновления закройте игру и скопируйте **BepInEx из ZIP** в каталог игры с заменой файлов плагина, сохранив весь `runtime/_internal`. Удалите старую отдельную `BepInEx/plugins/ValheimAIHelper.dll`, если она осталась вне папки плагина. В начале отчёта должна быть версия **0.8.1**. PowerShell, отдельный Python и второй клиент не нужны.

Проверка после обновления: без имени попросите **«возьми каменный топор»**, затем **«собирай одуванчики»**; во время генерации NPC должен продолжать прежнюю работу. Попросите **«не нужно больше собирать малину»** и проверьте пул. Откройте инвентарь через E и перенесите предмет в обе стороны. [Подробные сценарии](task-scheduler.md#что-проверить-в-игре).
