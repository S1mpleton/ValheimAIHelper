# Диалог с агентом

Начиная с 0.6.1 полный сохранённый обмен можно смотреть в игре: **Esc → Управление персонажем → Журнал → Диалог AI**. Резервная панель F8 содержит тот же просмотр.

Выберите запрос кнопками «Ранее»/«Новее». По умолчанию отображается последний; выбор раздела или страницы фиксирует текущую запись, чтобы новая генерация не прервала чтение. Возврат к самой новой записи снова включает следование за последними запросами. Указаны модель, время, длительность и назначение: игровой план, разбор чата или проверка подключения. Это просмотр; поручения по-прежнему вводятся в игровом чате.

- **Запрос** — фактическое тело запроса к модели: системные инструкции, текст задачи, снимок мира/инвентаря, используемая история чата, JSON-схема и параметры генерации. HTTP-заголовки в запись не включаются.
- **Ответ AI** — исходный текст ответа до разбора, проверки целей и нормализации статусов. Здесь видно даже невалидный JSON или фразу модели, не подтверждённую игрой.
- **Проверка** — план после проверки формата/целей по исходному снимку либо конкретная ошибка. Планировщик может затем отбросить устаревший ответ. Успешная проверка ещё не означает применение или исполнение действия: фактические результаты остаются в обычном журнале и приходят модели в следующем снимке.

Длинный текст разбит на страницы; поле просмотра доступно только для чтения. «Копировать всё» и «Сохранить всё» выгружают все три раздела, включая текст за пределами текущей страницы. Файлы появляются в `BepInEx/config/ValheimAIHelper/reports/Dialogue-…txt`. Экспорт доступен после завершения/ошибки/отмены запроса; F9 отменяет ожидание модели.

Запрос виден во время генерации. Ответ появляется целиком после получения: текущий транспорт использует `stream=false`. Просмотр и экспорт не отправляют дополнительные запросы нейросети и не включают размышления. Поля `thinking`/помеченные thought-части не записываются; Ollama продолжает получать `think=false`.

Хранятся последние **8 запросов**, только в памяти службы. На каждый раздел действует лимит 262144 символа; превышение помечается явно. Ключи и код сопряжения скрываются до сохранения текста в памяти и перед экспортом. «Очистить диалоги» очищает эту историю, не останавливает агента и не удаляет уже экспортированные файлы. Перезапуск службы также удаляет историю.

Обычный режим следования не обращается к модели, поэтому сам по себе не создаёт диалогов. Ошибка загрузки/метаданных до генерации может оставить раздел запроса пустым; причина будет в «Проверке».

## Отдельное окно на другом экране

В существующей локальной веб-панели появился раскрываемый раздел «Диалог AI». В нём те же запросы, страницы, копирование и скачивание. Это позволяет наблюдать обмен во время движения персонажа, не открывая игровое меню. Адрес службы виден в игровом журнале (`http://127.0.0.1:порт`); в автоматическом режиме код сопряжения лежит в `BepInEx/config/ValheimAIHelper/runtime-<PID>/bridge-token`. Вставьте его в форму локальной панели. В URL код не передаётся.

Встроенный чат приложения Ollama не получает эту историю автоматически: мод вызывает её [API `/api/chat`](https://docs.ollama.com/api/chat), передавая собственный массив сообщений. Просмотр реализован на стороне мода и его службы; установка другого чат-приложения не требуется.
