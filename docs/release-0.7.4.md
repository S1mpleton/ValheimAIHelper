# Valheim AI Helper 0.7.4

Добавлен каталог предметов из базы установленной игры, включая зарегистрированные предметы других модов. Полный список с prefab ID, названием на текущем языке, токеном локализации и категорией сохраняется в **`BepInEx/config/ValheimAIHelper/item-catalog.json`**. В наблюдениях сумки, выпавших вещей и урожая растений передаются стабильные типы. Неприменимые характеристики боя у ресурсов больше не выдаются за свойства предметов.

Ollama сначала разбирает предметное поручение отдельным коротким запросом, затем выбирает действие среди подходящих реальных целей. Предмет, количество и выбранный ID проверяются перед выполнением. «Собери малину» допускает подходящий куст/ягоды; если топора в сумке и наблюдении нет, помощник сообщает причину вместо выбора костра. Каталог описывает типы, а наличие вещей подтверждает текущий снимок. Синонимы по-прежнему понимает модель; правильность свободного русского текста у небольшой модели не гарантируется. Разбор виден как `item-intent` в диалоге AI и кешируется для текущего поручения; все запросы Ollama используют **think=false**.

Для выбранной передачи всей сумки добавлена отдельная проверка `item-scope`. Если она не подтверждает массовое поручение, выполняется один повтор разбора без варианта `all_inventory`; исходный выбор не запускается. Проверка добавлена после случая, когда малая модель поняла пять камней как всю сумку; она также зависит от правильности ответа модели.

Открытие инвентаря через **E** теперь обрабатывается напрямую по выбранному NPC и отложено до следующего кадра после нажатия, как при штатном обмене с сундуком. Сохраняется кнопка **Esc/F8 → Персонаж → Инвентарь NPC**. Окно использует ту же сумку NPC; обмен останавливает его, а продолжение следования/AI запускается вручную. В журнале `npc-inventory` разделены стадии E, запроса, открытия и закрытия. По присланному отчёту без записи попытки и исключения точная причина прежнего отказа E не установлена; отрисовка в настоящей игре требует проверки.

Резервная обработка E использует штатную наведённую цель после обновления человека, учитывает допустимость ввода и уже обработанное нажатие. Чат, меню и обычные сундуки сохраняют своё поведение.

Для обновления закройте игру и замените **BepInEx** из ZIP, сохранив весь каталог плагина вместе с `runtime/_internal`. Удалите старую отдельную `BepInEx/plugins/ValheimAIHelper.dll`, если она осталась. В начале журнала должна быть версия **0.7.4**. PowerShell, отдельный Python и второй клиент не нужны.

Локально прошли **267 Python-тестов, 181 C#-тест**; DLL собрана без предупреждений и ошибок. Настоящая Qwen3:1.7B через Ollama с think=false на искусственных снимках выбрала отказ для отсутствующего топора, куст для малины и передачу ровно пяти камней при постороннем предмете первым в сумке. Эти три контрольных запроса не подтверждают работу пользовательской Llama 3.2 или понимание всех формулировок.

Автоматические проверки кода и протокола выполняются отдельно от игрового запуска. **Valheim 1.0.21 в среде разработки недоступен**, ссылочный SDK — 0.221.4. Открытие окна, реальные переносы, сохранение и поведение NPC проверьте по [сценариям](https://github.com/S1mpleton/ValheimAIHelper/blob/main/docs/testing.md). Прежние ограничения по хосту и набору действий сохраняются.
