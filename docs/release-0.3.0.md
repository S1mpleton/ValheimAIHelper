Valheim AI Helper 0.3.0 — управление из игры и чата лидера.

- Esc → «Управление персонажем»: окно с элементами оформления Valheim, вкладками персонажа, AI и журнала.
- Команды из чата выбранного лидера: `!ai следуй`, `!ai стоп`, `!ai статус`, `!ai <задача>`. Проверяется сетевой отправитель, мод лидеру не нужен.
- Непрерывный мотор и фоновый план из 1–6 шагов: следование, прицеливание/атака, блок/уклонение/отступление, еда/экипировка, подбор/растения/двери. Модели передаются расширенные наблюдения и результаты шагов.
- Бой, автоматическая еда и чат включаются в панели. Старое значение AllowCombat сохраняется при обновлении.
- В Windows-архив включена локальная служба: мод запускает и завершает её автоматически. Python и PowerShell для обычного запуска не нужны.
- Журнал с копированием/экспортом отчёта и маскировкой ключей.

Установка: закрыть игру и прежний мост; скопировать папку BepInEx из ZIP в каталог Valheim. Сохранить вложенные runtime и _internal. Старую отдельную `BepInEx/plugins/ValheimAIHelper.dll` удалить, если такая копия осталась. BepInExPack Valheim устанавливается отдельно. Затем войти в мир, F8, выбрать лидера и настроить AI.

Это экспериментальный сценарий «следовать → сражаться → выживать» с отдельным клиентом помощника. Крафт, стройка, шахты, сундуки, лодки и возрождение ещё не реализованы. Сборка использует ссылочные библиотеки Valheim 0.221.4; совместимость GUI/чата/боя с установленной версией игры требует игровой проверки. Автотесты и запуск упакованного сервиса не заменяют тест в Valheim.

Вложения: готовый Windows ZIP и SHA256. Исходники доступны по тегу релиза.
