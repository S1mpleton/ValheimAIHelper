# Навыки и атомарные шаги — 0.7.1

Полезная схема: **пожелание игрока → навык или небольшой план AI → локальные шаги мода → проверенный результат**.

Модель интерпретирует обычную речь и выбирает действие по смыслу. Одна точная фраза «следуй за мной» остаётся быстрой командой; синонимы разбираются моделью. Мод не поддерживает словарь всех перефразировок.

Дробление заканчивается на известных игровых навыках. Путь, поворот, кратковременный ввод и расстояния выполняются модом. Если спрашивать модель о каждом шаге или постоянно выдавать ей координаты лидера, растут задержки, цена контекста и риск устаревших целей.

| Навык | Локальные шаги | Подтверждение |
|---|---|---|
| `follow` | Проверить личность лидера → удерживать/возобновлять дистанцию → запросить полный маршрут → идти по узлам → ограниченно восстановиться при препятствии | Непрерывное исполнение до смены поручения/стопа; не требует нового ответа модели каждый цикл |
| `pickup` | Найти настоящий ItemDrop → подойти → проверить место/вес/владение → штатный Pickup | Реальный прирост инвентаря |
| `give` | Зарезервировать реальные вещи → подойти к движущемуся получателю → сбросить количество → измерить уменьшение | Подтверждённое количество рядом с получателем, с защитой от повторного commit |
| `interact` с растением | Подойти → штатное взаимодействие → проверить флаг сбора/появление вещей | Растение собрано; если урожай выпал на землю, следующий навык `pickup` пополняет сумку |
| `gather` | Проверить наличие нужного инструмента/tier → экипировать его → подойти → штатные удары | Изменение ресурса; полученный лут подбирается через `pickup` |

«Принеси камни» может состоять из `pickup → свежее наблюдение с новым ID сумки → give`. Уже имеющиеся вещи сразу передаются через give. Нельзя заранее придумать ID будущего предмета.

В Ollama выбирается **один навык за ответ**, затем поступает свежий результат. Это уменьшает ненужные `move/look` и ошибки маленьких моделей в длинных планах. Навык при этом может иметь несколько локальных шагов. Облачные планы по-прежнему допускают до шести проверяемых шагов; провал предпосылки отменяет зависимые действия. Передача нескольких стопок — одно составное действие.

Сопровождение из кнопки AI — известная роль: модель видит follow и подходящие действия защиты/еды/экипировки, а не случайные прогулки вперёд. Свободное поручение/ожидающий чат возвращают полный применимый набор. Без лидера обычное сопровождение ожидает на месте, не вызывает модель для бессмысленных прогулок. Подтверждённый follow не перепланируется по одному только истечению интервала API; новые сообщения всё равно обрабатываются.

Объекты сообщают своё взаимодействие: выпавшая стопка — pickup, растение — interact, залежь/дерево — gather с инструментом. Разрушаемый компонент сам по себе не делает гриб ресурсом для кирки. Недоступные из-за отсутствия инструмента варианты исключаются из локальной схемы и проверяются повторно в моде. Быстрый JSON не гарантирует понимание — слабая модель всё ещё может выбрать неудачное доступное действие.
