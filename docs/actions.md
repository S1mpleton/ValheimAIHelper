# Действия NPC и проверка — 0.7.0

Модель выбирает смысл поручения и короткий план. Мод проверяет ID, остатки и ограничения игры, выполняет действие и сообщает реальный результат. Правильный JSON не является доказательством выполнения. В NPC-режиме доступны **38 действий** из общего каталога 41.

## Предметы

В снимке — собственный инвентарь с ID/видом/качеством/вариантом, количеством, экипировкой, весом и признаками еды/квестового предмета. Выпавшие `kind=item` — реальные загруженные ItemDrop с действительным ZNetView, до 128 м и 80 ближайших стопок. Число/усечение передаются явно. Это не растения, декорации или вещи закрытого сундука.

| Действие | Состав | Пример проверки |
|---|---|---|
| `pickup` | Найти ItemDrop → полный путь → подойти → запросить владение при необходимости → проверить место/вес → Pickup → измерить прирост | «Гоша, подбери выпавший камень» |
| `drop` | Выбрать резерв вещей → проверить все остатки → DropItem → измерить уменьшение | «Гоша, сбрось 7 камней» при стопках 5 + 3 |
| `give` | Выбрать реального игрока/резерв → подойти к его текущему месту → повернуться → проверить расстояние/остатки → DropItem → измерить уменьшение | «Гоша, дай мне 7 камней» |
| `open` | Подойти к контейнеру → проверить доступ и владение хостом → открыть отдельную NPC-сессию → включить содержимое в следующий снимок | «Гоша, открой сундук» |
| `take` | Проверить открытую сессию, ID и количество → native MoveItemToThis в сумку NPC → проверить фактический перенос и вес | «Гоша, возьми 3 камня из сундука» |
| `deposit` | Те же проверки → native MoveItemToThis из сумки NPC в контейнер | «Гоша, положи 3 камня в сундук» |
| `stack` | Проверить доступ → перенести совпадающие виды/качества в контейнер через native inventory methods | «Гоша, сложи совпадающие предметы в сундук» |
| `close` | Освободить NPC-сессию и in-use контейнера; окно человека не закрывается | «Гоша, закрой сундук» |
| `equip`, `unequip` | Выбрать настоящий предмет → native UseItem → проверить состояние экипировки | «Гоша, возьми дубину» |
| `eat`, `use` | Проверить CanEat/тип расходника → native UseItem → проверить расход/состояние | «Гоша, поешь» |
| `use_on` | Найти станцию и вещь в сумке → подойти → native UseItem станции → проверить изменение количества | «Гоша, добавь уголь в плавильню» |

Для `give`/`drop` модель выбирает `selection`:

- `exact`: указанное количество, включая несколько одинаковых стопок. Группа определяется видом/качеством/вариантом; другие вещи не подставляются.
- `all_matching`: все стопки выбранного вида. «Гоша, отдай все камни».
- `all_inventory`: все неквестовые вещи, в том числе экипированные. **«Гоша, отдай мне все свои вещи»**. Это одно составное действие, а не план на каждый слот.

Передача — сброс на землю **рядом с получателем**, а не запись в его инвентарь. Далеко от него NPC вещи не сбрасывает. При исчезновении/изменении резерва до сброса операция отменяется. При частичной мутации сообщается реальное количество, исходная выдача не повторяется автоматически. Квестовые предметы не сбрасываются. Native AutoPickup для NPC выключен, чтобы он не забирал выданное обратно.

Если предмет только на земле, сначала нужен `pickup`, затем новое наблюдение и новый ID сумки для передачи. Содержимое закрытого сундука не раскрывается; открытый человеком сундук имеет приоритет. В первой NPC-версии сундук должен быть доступен NPC и принадлежать сетевому хосту.

## Остальные действия

| Действия | Состав и ограничения |
|---|---|
| `wait` | Короткая пауза, обновление наблюдений |
| `follow` | Найти лидера → проложить путь/подход → поддерживать расстояние; непрерывный шаг |
| `move`, `jump` | Движение к точке до 30 м/вперёд, штатный прыжок с проверкой земли/выносливости |
| `look` | Поворот взгляда к наблюдаемой близкой точке |
| `attack`, `secondary_attack` | Найти враждебную цель → подойти/прицелиться → native основная/вторичная атака |
| `defend`, `dodge`, `flee` | Блок лицом к врагу, штатное уклонение, безопасный отход |
| `hunt` | Атака дикого неприручённого животного при разрешённом бое |
| `gather` | Дойти до ресурса → проверить подходящий исправный топор/кирку и tier → штатные удары; лут — отдельным pickup |
| `interact` | Подойти к растению/двери/объекту → native Interact; станции/сундуки используют NPC-обработчик |
| `craft`, `upgrade` | Проверить известный рецепт, материалы/уровень станции/место → выдержать операцию → повторно проверить → native inventory + ConsumeResources → подтвердить предмет/качество |
| `repair` | Подойти к доступной станции → проверить рецепт/уровень/repairable → восстановить допустимую прочность → подтвердить |
| `hide_weapon`, `show_weapon` | Штатное убрать/достать экипированное оружие |
| `sneak`, `unsneak` | Штатное переключение приседания и подтверждение состояния |
| `rest`, `stand` | Сесть/получить Rested при безопасных условиях; встать/прервать эмоцию |
| `guardian_power` | Активировать доступную силу с обычным восстановлением |
| `emote` | Штатный разрешённый жест |
| `speak` | Одно сообщение NPC в игровом чате |

`build`, `repair_building`, `sleep` не объявляются NPC в 0.7: нужны отдельные реализации без камеры/кровати человека. NPC не блокирует сон хоста. Особые рецепты с выбором одного ингредиента отклоняются. Рыбалки, торговли и корабельного автопилота нет; телепортация NPC через порталы запрещена.

## Последовательность проверки

1. Создайте NPC в своём мире одним клиентом. Продолжайте ходить/прыгать человеком при активном follow; мышь и хотбар должны действовать на человека.
2. Дайте NPC подобрать камень с земли. Откройте журнал: предмет должен исчезнуть из наземных объектов и появиться в сумке NPC.
3. При 5 + 3 одинаковых камнях попросите 7. На земле рядом с вами должно оказаться ровно 7, у NPC остаться 1. Повторное обновление снимков не выдаёт ещё 7.
4. Попросите «отдай все камни», затем «отдай мне все свои вещи». Убедитесь, что модель выбирает all_matching/all_inventory; экипированное передаётся только при соответствующей просьбе, квестовые вещи сохраняются.
5. Отойдите во время доставки; NPC должен изменить путь к вашему текущему месту и не сбросить вещи на прежней позиции.
6. Проверьте стену, лестницу, разные этажи, перепад и недоступную воду. Должны быть ограниченные повторы и причина отказа, без телепортации/прохода сквозь стену.
7. «Следуй за мной» должно работать без модели. «Гоша, пошли» — запрос к AI, затем выбранный по смыслу follow. Это видно в «Журнал → Диалог AI».
8. Сохраните/перезайдите: тот же NPC и вещи, повторное «Создать / найти» не дублирует. Проверьте надгробие NPC в тестовом мире: человек не должен умереть/возродиться вместе с ним.

Здесь выполняются автоматические проверки кода и протокола. Реальная физика и визуальное поведение требуют Valheim; [состав проверок](testing.md).
